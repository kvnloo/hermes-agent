# council-autoresearch-loops

Use when running a requested model council, a measured keep/revert autoresearch loop, or a cross-model benchmark on the owner's model seats.

## Rules

1. Give each loop one scored objective. Recover the named local repository, branches, existing experiment and prior program first; reuse the published loop rather than invent an optimizer. Freeze PROGRAM.md with real workload, metric, hard gates, tracks and separate fit axes. Keep side work outside the program and probe novel candidates cheaply before matrix admission.
2. Probe the real hardware and a representative longest-context end-to-end workload before choosing matrix size. Apply measured RAM/VRAM admission before heavyweight imports, preserve other jobs and host guards, and bound resource waits. Record capacity exits and resume conditions; count skipped ticks, flag three consecutive skips and report a no-progress streak.
3. Build and qualify the referee before workers. Interleave ABBA against track incumbents, freeze the eval set and compute paired uncertainty with A/A noise and every quality gate. Use the declared track's threshold rather than mixing formulas; changing arms, metric, gates, referee or data starts a new epoch with re-baselines. Keep failures in an append-only ledger.
4. Separate model/engine tracks from implementation lanes and speed from cross-model quality/fit. Use independent quality evaluation, label proxy-only quality as provisional and retain owner listening where needed. For tiny-model tracks, beat trivial controls and short programs on a sealed chronological/session split before training; measure the teacher on the same encoding.
5. Use free-first, fixed-budget optimizer trials and a matched random-mutation control. Unlock a paid mutator only after a held-out KEEP and superiority to random at equal budget; measure paid lift per token. Keep owner-trace families on local models. Use free reasoning/verification for suitable judgment and scripts for experiments, reserving council or Opus for the declared stall/final-audit role.
6. Give every worker one owned worktree/branch and editable experiment surface, with no shared-device access. Give directions three rounds before keep/drop/redesign. Check stalls before each experiment: three non-keeps trigger one council round, then two rounds plus profiling/research, then retarget/stop with the null result; also check every ten experiments.
7. Follow references/recipe.md for requested native seats and rounds. State account and worker count, preflight each exact route, and require exit zero, actual text, usage success and observed model equality. Keep unavailable or substituted seats unqualified and the council incomplete. Run independent openings, then fresh cross-examination with actual peer text and explicit retractions. Let the council audit and rank experiments, preserving measurements as the decision authority.
8. Follow references/tool-free-model-evals.md for model comparisons. Validate the scorer against released logs before spending calls, pin prompts/weights privately, use stdin, isolate answer keys and audit tool use. Freeze budgets/effort/retry policy, preserve empty and failed attempts, and keep recovered multi-segment or owner-run Task results separate from strict tool-free Chat results. Move compute rather than provider credentials to remote sandboxes.
9. Preserve phone battery, thermal and focus-change gates. Separate anytime screen trials, which only nominate ratios at or below 0.85, from idle-gated confirm trials, which alone can KEEP. Keep exact device identity and owner UI authority; use PID-qualified cleanup for owned on-device jobs as well as host runners.
10. Use owner-armed Hermes /goal for unattended continuation, or the stated thread-bound T3 scheduled-task exception. Retarget the existing task by scheduledTaskId, honor STOP, inspect the previous job first and explain host liveness and how to stop it. Keep one bounded run mechanism, durable resumable artifacts and exact owned-process cleanup; inspect partial worker output before redispatching and wait for a changed blocker.
11. Verify worker artifacts and hashes on disk before accepting build or benchmark claims. Run evaluators on real referee directories, inspect outliers and gate code, rebuild the candidate and run a fresh ABBA block before announcing KEEP. Separate template reuse from mechanism, preserve no-leftovers and shared-store isolation gates, and use references/workspace-surface-tracks.md and references/agentsys-loop.md for their specific protocols.
12. Keep the cross-repo experiment map in kvnloo/z0 registry/experiments.yaml with epoch, controls, metric, gates, data tier and runner status. Render issues from the map and merge its definition before sharing canonical links. Preserve trace-derived data and council text privately and obtain publication authority before public pushes. Report validated cells, held-out results, provisional gates and full-scope completion separately from dispatch, installation, waiting or convergence.
