# Public story source brief

1. Recheck existing briefs rather than preserving stale source identities. GitHub issue numbers can resolve to PRs; inspect returned URLs/type and retrieve the actual PR.
2. Parse account inventory in code. A result hitting its requested limit is bounded, not exhaustive. Verify principal repositories individually; record visibility for every map row. A public issue mentioning a private locator does not authorize reproducing it.
3. Use indexes for discovery and canonical files for claims. If an index is warming, document it and use bounded filesystem/QMD/GitHub content fallback. Local indexed READMEs may differ from public branches. Do not rebuild indexes for storytelling research.
4. Separate architecture, source implementation, exact-revision tests, runtime activation and demonstrated outcomes. Label simulated cost models, reported experiments, fixtures and unrun stages.
5. Explain diagrams through the distinction each exposes: authority crossing, refusal, revision-bound evidence, interrupted obligation, independent review or owner acceptance. A moving edge is not live enforcement evidence.
6. Construct the improvement argument as contract → admissible action → receipt → frozen comparison → candidate → separate promotion. Structure alone does not establish operational learning or weight-training gains.
7. Bind totals to snapshots. Initial diagrams, expanded models and a privacy-minimized presentation tape can have different legitimate counts. Keep research-wave requested artifacts, received artifacts and synthesis comments distinct; do not silently reconcile separate job-log snapshots or exit-code cohorts.
8. Recover owner voice from canonical read-only messages. Exclude delegated briefs, summaries and pasted model synthesis; dedupe imported rows. Mechanically verify literal quote substrings and record date/profile/session/message ID. Private-source quotes still require publication approval.
9. Never send private history to cloud ranking tools. Rank public-only evidence separately. Timeout and bounded searches are coverage gaps, not proof of absence.
10. Deliver an operator-only brief with a privacy warning, public-link allowlist, exact evidence/caveats and publication hazards. Generate and verify citations. Research does not authorize builds, repository edits, posting or publication.
11. Reconcile dated synthesis comments with fresh exact-target PR metadata and bodies before assigning public status. A later preview merge supersedes an earlier draft-status statement but does not establish deployment or model-visible use; later source-byte hydration repairs likewise supersede older cached-snippet descriptions.
