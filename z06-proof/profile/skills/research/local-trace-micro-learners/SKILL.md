# local-trace-micro-learners

Use when improving agent speed, evidence selection or decisions with local traces, cheap learners, small models, protocol evolution or weight-editing studies.

## Rules

1. Recover the owner's objective, cross-harness evidence and current compute inventory before choosing a mechanism. For intelligence, optimize verified decisions and repeated-correction rate. For speed, measure touchable wall time with `timebudget.py`, `turns.py`, `writes.py` and `redundancy.py` in `/mnt/zer0models/zer0-tier/experiments/fly-mushroom-hillclimb/`; read its README and RESULTS before rebuilding.
2. Reconcile the lane handoff, backlog, specialist conversation, native job, log and final artifacts before resuming. Record one execution owner, hypothesis, held-out evaluation, utility and approval gates. Extend Chief's provenance-linked ask catalog through its owner. Collect active results rather than starting duplicate censuses, schedulers or chats. Check the study STOP sentinel first on scheduled ticks.
3. Export source databases and Git read-only into private typed graphs and decision-event JSONL under experiment `data/`. Keep changing facts external to weights with source IDs, valid time and requested/decided/supersedes/tested/deployed relationships. Validate authorship and exclude machine briefs or shared-account material from owner identity. Obtain owner permission before publishing private data or derived numbers.
4. Research actual applications before presenting a biological or systems design and cite returned sources. For external inference, derive public trace rows with `s0_public_attr.py` and `s0_public_family.py`, requiring all session repositories public and the row context scrubbed. Keep private families local under O18; a public-repo cwd alone establishes neither provenance nor privacy.
5. Start the trace-learner arm with a frozen cached embedder and 2-3-choice gates, comparing hash n-grams. Train one learner per family/site on the oldest 70%, compare a gradient-trained linear readout, and judge prequentially once on the newest 30% against the incumbent. Require McNemar z>1.96 for classification or bootstrap 5th-percentile AUROC gain >0 with at least eight positives for ranking. Gate promotion rather than choosing winners manually.
6. Compare allocator rankings with frequency, random and oracle at budgets 10/25/50/100. Report proxy payoffs and touchable hours in RESULTS.md. Keep generation and weight editing as distinct experimental arms, and wait for owner approval plus the next gated release before live shadow-network wiring.
7. Use the exact named loop, including `kvnloo/autokernel` when requested. Profile trace-derived p50/p90 shapes in the real dtype, verify MODEL_SHAPES and MODEL_DTYPES, compare correctness against fp64 and reject fallback-size scores. Keep harness changes safe before reset-based experiments in an owned study. Time kernels on the target 3080 Ti; use scripted/free config sweeps and reserve paid code lanes for structural rewrites. Follow `references/kernel-hill-climbs.md`.
8. Qualify replay/ontology adapters against the real incumbent on identical tasks with inputs frozen before outcomes. Verify returned content and task completion, pin source/registry hashes and reuse `registry/experiments.yaml`. Keep historical recommendations, micro-contract tests, sandbox progress and actual network integration as separate evidence.
9. Audit protocol-evolution outputs before new inference: snapshot observation time/hash, parse failures, unique IDs, expected-ID equality, error categories and actual model. Compare held-out `test_live` with the best zero-cost baseline and same-budget random mutation; label validation scores training signals. Preserve transport/funding failures and route them to the execution owner without silently rerunning holdouts, switching providers or topping up credits.
10. For model selection, inventory paths/revisions without loading weights, verify model-card/license/serving claims and compare retrieval, small, dense and fitting sparse candidates. Measure cold/warm load, prefill, streaming TTFT and p50/p95 task latency separately. Freeze pre-ask evidence, split by session/time with repository holdouts, and grade the same downstream agent's completion and corrections. Follow `references/slm-selection.md` and `references/agent-time-budget.md`.
11. For weight editing, name a real measured failure and run practice-tuned no-model controls beside the unedited model before editors. Count distinct states, weight sessions equally, keep audit and scored replay policies identical, and require paired raw-output regrading with exact ID coverage. Keep dev work separate from once-only sealed transfer and make the sealed-test script refuse existing output. Label confidence intervals crossing zero as inconclusive.
12. Qualify a remote editor through `references/remote-weight-editing-sandbox.md`: public runtime/practice only, controller-held credentials, read-only pinned model/practice mounts, one writable session directory, no network and enforced resource limits. Validate adversarial tensor artifacts outside the editor, stage immutable bytes and exercise original-to-edited-to-original in fresh processes. Keep practice RPC bounded to known IDs and allowlisted fields, with paths controller-owned. Prove actual session integration separately from CLI, confinement or validator smokes.
13. Respect O19 spend approval for Modal and inventory free CPU workers before repeating a blocked tick. Treat inference capacity and editor quota as separate. Preflight each editor's actual model, test adapters with stubbed `gpu_job`, preserve active outputs and use `<cell>/work/eval/` for session-owned evaluations. Refuse an empty edited directory as an edited model. Keep launcher dependencies in the repository.
14. Run long steps as named memory-capped user units without `--wait`, checkpoint caches atomically and gate GPU training on free VRAM. Use script files for large trace analyses, bounded short fallbacks when units are unavailable, and `bws-env-exec --scope <s> -- <cmd>` for secrets. Report completed batches/artifact paths and measured intervention gains separately from estimates, controls, adapter readiness and unrun transfer checks.
