# fframestudio-editor-core-qualification

Use when qualifying fframestudio document, editor, review, import, export or browser interaction changes.

## Rules

1. Compare the candidate base with current integration and the worktree registry. Keep root/served checkouts and `~/fframestudio/projects` unchanged. Use `tools/verify-editor.mjs` with a TMPDIR library copy and an owned bridge on a free loopback port. Pass explicit `--root`, `--port` and `--no-config` to every test bridge, including ACP launchers.
2. Read bridge option parsing before unfamiliar flags. Assert discovery-config bytes and mtime remain unchanged after every owned child exits, reporting booleans rather than credentials. Test a deliberately flag-less launcher only inside disposable HOME. Poll `/health` with a deadline and child-exit checks, retain failure state before cleanup, and stop only owned processes.
3. Run document tests, real browser workflows, ACP and performance as separate gates. Exercise new visible tools through clicks and the shared action registry. Retain baseline/control results, all failures and repeated-run tails. Measure command-to-layout-ready, rAF scheduling and compositor presentation separately, and serialize latency gates before screenshot jobs.
4. Exercise repeated real handle drags using measured scale, MutationObserver checks on unrelated clips, bounded Story/Timeline DOM counts, multi-video rollback and Undo. Test resize/collapse/reload, user width persistence, all slate tabs and the last Story card. Inspect owner-size, short-laptop and 390px views, complete timeline bounds, aspect ratio, target dimensions and actual hit testing.
5. Decode posters with one detached paused decoder and the existing resize/cache worker. Bound work to connected cards, retain visible type-colour fallbacks, and invalidate by source range, speed, media identity and start. Keep preview playback independent. For async job updates, persist terminal state and sequence before REST/SSE publication and reject stale snapshots.
6. Qualify theme fixtures with `--theme-home <fixture-home> --no-config`. Test atomic palette writes, symlink swaps, fixed-theme reload and computed contrast including focused shortcuts. Run system-theme assertions before persisted Dark menu tests. Keep palette/token mapping isolated and read real palettes without modifying them.
7. Normalize saved export input with canonical migration/validation at the disk/render boundary while preserving saved bytes. Preserve attachment audio or reject unsupported soundtracks before probing. Bound FFprobe/FFmpeg protocols, demuxers, time/output and decoder/filter/encoder threads. Check realpath containment, links and nonregular files. Run `node --test --test-concurrency=1 test/doc/render.test.mjs` and independently count frames and decode audible samples; follow `references/saved-project-export.md`.
8. Qualify recorded review through `references/recorded-review.md`. Keep one mounted visible film, one speech/typed/pencil instruction bar and replayable conversation entries. Pin project/video/revision, separate recording and source clocks, and test per-video drafts, async saves, cancellation, late permission/transcript results, finite replay duration, decoded ink/text positions, Send finalization and failed-delivery retention.
9. Keep live subscription voice separate from recorded Whisper/fixture ACP. For requested live voice, use `gpt-live-1-codex` through the existing OAuth owner and Hermes delegation, keeping credentials there. Require final `turn.done`, meaningful final text, audible samples, an unapplied proposal and canonical admission/billing receipts. Settle timed-out owned admissions before retrying, and limit automated approval to the disposable project's numeric proposal JSON.
10. Trace live ACP callbacks against the bridge library root and allow only the current project's numeric proposal files. Inspect a real proposal before Apply, then exercise Apply/Reject, Undo/Redo, Save and disk readback. Keep agent shell authority explicitly separate from callback confinement. Report physical microphone, real-model and Android share-sheet coverage only when exercised.
11. Qualify hosted mode under a static server with generated CSP. Keep fresh libraries empty, imports in IndexedDB limited to project JSON and referenced media, and pre-connection traffic same-origin with no import POST/PUT. Test recovery, downloads, handle conflicts and permission re-request separately from native picker UI. Measure retained counts/bytes with `tools/folder-import-footprint.mjs` and inspect scrolled phone entry paths.
12. Preserve procedural source clones and `metadata.procedural`; pin working-copy overrides to source hashes and write Rust only into fresh copies. Verify round trips, actual Cargo backend features, native frame counts/PTS and audio. Use explicit RGB FFV1 pixel format and integer-frame timestamp reconstruction where needed. Keep unlicensed imagery and unknown-rights posters/videos out of publication, using metadata-only cards instead.
13. Exercise specialized checks at their real boundary: `tools/node-graph-journey.mjs` and `npm run test:comfy` for graph interaction, DOM/CSS versus independent CLI eval for motion parity, and aggregate-only Taste receipts with revision/brand locks. Keep fixture generations separate from real-model VRAM/latency and transport simulations separate from real X embedding. Follow indexed source details for these scoped journeys.
14. For an owner preview, provide a reachable disposable instance and a short click path using `references/manual-preview.md`. Keep tokens in private environment delivery, preserve existing Tailscale mounts, verify exact HTTPS Origin and streaming/WebSockets, and use one-shot authentication handoff without exposing reusable credentials. Keep the instance available through review and disclose untested microphone/model behavior.
15. Run `bash scripts/check-no-local-paths.sh` before publication and scrub inherited logs without discarding failures. Compare suspected failures against an unchanged origin/main scratch control before assigning cause. Record exact commands, counts, phases, unsupported semantics and remaining union/CI/device gates. Keep static offloads separate from locally run Node/Chromium/FFmpeg work.
