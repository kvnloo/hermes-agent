# Same-chat Dash agent control

## When to Use
Use for authenticated agent navigation and expressive overlays attached to an existing Dash conversation, including qualification and parent rollout handoff.

## Workflow

- Discover the actually served Metro and shared bridge WorkingDirectory plus source SHAs with read-only systemd/Git checks. Branch an unserved worktree from that exact app revision. Never restart shared services, install an APK or operate the daily phone as a worker.
- Search FFF first, then state any retrieval gap and use bounded local search. Inspect `app/src/debug/nav.ts`, AnnotationRoot/store, app bridge socket, BridgeAuth and existing libfx LiveSurface before adding transport. LiveSurface's embedded HTML is not app-wide control.
- Reuse the authenticated Dash socket and bridge HTTP host/origin boundary. Bind a random scoped surface capability to the exact socket principal and runtime client/host/profile/session/local-chat tuple; never broadcast commands or give the agent a vault/bridge execution token. Store grants only in an owner-private directory and revoke on disable/disconnect/identity expiry.
- Keep consent local. Disable Guide until the complete attached host/profile/session exists; an empty host can allow an early toggle which is invalidated when hello arrives. Never create/select/reset a chat to make the demonstration work.
- Push allowlisted screens above the mounted Chat and return to that existing route. Reset/pop-to-Main destroys the composer's local draft. Exclude send/approval/delete/model/route-param actions from generic navigation.
- Keep expressive primitives in their own pointer-transparent SVG layer. Agent clear, dismiss and TTL must never call user-ink clear/discard/send. Reserve real space for visible dismiss/disable controls: an absolute toolbar over the navigation pager passed geometry gates but looked overlapped in the actual screenshot.
- Validate exact target, route/layout generation, expiry, normalized geometry/insets, semantic anchors and bounded payloads. Cache idempotent receipts and timeout tombstones; an ack timeout is not permission to replay navigation. Report rendered only after a real React layout commit/frame fence and state readback.
- Run all installs/typechecks/tests/mutation/exports/screenshots through admitted `fleet-build --node mbp`. Queue thermal exit 75; never fall back to groot. Use a locked, worker-owned cache and fetch logs/screenshots even on failures.
- Prove the actual Expo app against an isolated real bridge entry point with fixture credentials/data. Select the Chats tab explicitly: Dash cold-opens Orchestra. Use DOM-content-loaded plus locators rather than network-idle when live polling prevents an idle window. Exercise the real CLI, highlight, annotation open, warp/back, draft/queue retention, user ink gesture, TTL/clear independence and owner-disable 401 readback.
- On Web, initialize CanvasKit before importing App, not merely before importing InkCanvas: eager ShimmerText imports Skia, whose Web API captures global.CanvasKit at module evaluation. A real pen gesture exposed an undefined PathBuilder even though annotation-open state and navigation receipts passed. Keep this bootstrap Web-only; native registration needs no WASM.
- For a Dash Playwright army, isolate browser contexts AND each real bridge's HOME/config/credentials/outbox/port; use a private PID namespace because HOME alone does not hide OMP sessions discovered through `/proc`. Target the exact chat row created by the test, not the first roster row. New chat opens a full screen; return to Chats and select its row to qualify the chat window.
- Keep fixture lifecycle realistic: a returned ACP session id without a native roster row triggers ended-chat reconciliation. For persisted-session journeys, expose an owned fixture OMP process plus open native transcript and a fixture Hermes SQLite session row; assert both through the real roster before UI actions. On Bun, `process.title` does not update Linux `/proc/self/comm`; write the fixture's own comm explicitly. Keep a separate missing-roster regression rather than hiding that product behavior.
- Route unattended browser armies to an owned headless Sway with a private XDG_RUNTIME_DIR and fail closed if its socket is absent; the socket may also be named `wayland-1`, so its name alone does not establish physical-display isolation. Record video/trace and compositor-client evidence. Probe eight workers, retain environment timeouts separately, and back off based on observed errors/throttle deltas. Benchmark launch/context/page/action overhead separately from full Dash suite time; the Playwright docs describe contexts as fast and cheap but provide no millisecond SLA.
- Distinguish tested source from deployment. An app-only JS promotion cannot provide new command routing on an old shared bridge. Give the parent an exact committed SHA, paired bridge rollout gap and scoped CLI demonstration. Never call Web fixtures real model turns, native IME/Fast Refresh or phone pixel acceptance.
