# Astra Blender modeling

## When to use

Use for the locked-subject reconstruction: one photograph, one camera, the easiest plant or one facade first. Do not start with the whole house. Also use for later mesh edits, material application, and contact corrections on that same house. Not for Codex CLI code tasks, and not for creative plant authoring that already has its own skill.

## Procedure

1. Send Blender modeling to Astra through `delegate_task` when this profile pins delegation to an Astra model. Do not model in the parent session. Do not route scene work through the Codex CLI skill: that path is for git-repo code tasks and does not own the scene lock.
2. Read the subject lock before the issue list. The locked still and its named next class are the critical path until that plant or facade scores. A site overview, orbit, identity packet, provenance append, or local checker is not a substitute when the lock says one subject first. A finished preview, contact fix, or extraction is not a stopping point: verify it, then continue the locked class. Do not close with a question or an offer to continue. Explicit forbids still bind — skip that action and take the next allowed step of the same subject. Do not halt the lane because one action is separately scoped.
3. Give one worker the shared scene lock. Other lanes do non-Blender prep or leave a ready queue. A second Blender launch that returns slot-busy is a scheduling fact, not a user decision.
4. On deferral, stop that launch only. A failed or running checkpoint in that runner state directory blocks every later job until that attempt is reconciled: confirm the child is gone, preserve the log, reconcile only that attempt, then launch a new job id from a new queue file. Do not edit a queue whose request fingerprint is already recorded. When the lock is free and a fresh memory read admits the staged queue, run it without asking. If that job cannot admit, continue the locked subject's named next class without Blender. Do not leave it for a paperwork lane. Do not lower the reserve or rewrite an unmeasured peak to force admission. A no-render measured peak is not a render peak. Clearing VRAM, or finding the GPU already idle, does not admit a ram_reserve deferral: rerun the staged queue only after a fresh effective-memory read meets its required figure, and do not kill unrelated processes to manufacture that headroom. Stop only when every remaining action is forbidden, deferred, or blocked on a human label the files do not contain.
5. Scripts that run inside sanitized Blender must not import packages that interpreter lacks. Write diagnostic images with the stdlib or bpy, not Pillow. When Blender reports missing stdlib modules such as `math` or `_posixsubprocess`, clear inherited `PYTHONHOME`, `PYTHONPATH`, and `VIRTUAL_ENV`, and put the system interpreter directory first in the child `PATH`; clearing Python variables alone may still select the harness interpreter. Use that sanitized environment for host gate scripts when their scientific dependencies are installed in system Python.
5a. Preflight a required independent CLI judge before rendering iterative rounds. If authentication expires, preserve the real capture, gate output, submitted prompt and raw judge error, mark the round unkept/unscored, and stop promotion until the specified judge works. Never substitute the render worker's own score for a required fresh judge verdict. When the owner authorizes a replacement judge harness, calibrate it on the last kept capture before judging new candidates; retain the historical verdict and record any score drift. Fresh Hermes one-shots can use `--provider anthropic -m claude-opus-5-5 -t file,vision --query-file`; preserve the rubric verbatim and provide original-coordinate `vision_analyze` crops. Limit repeated loads per image and state gate implementation facts separately from the rubric. A conditional/net-positive recommendation is not a strict nonregression keep when the judge identifies a new defect.
6. Verify the child's files before reporting: hash, runner status, and a decoded image when image evidence is in scope. For geometry-only work that forbids rendering, verify saved/reopened authored-state and contact receipts instead; do not create a render to satisfy a generic evidence checklist. A subagent summary is not evidence. State the absolute path. When the user asked to see the image, also open it under the focus-safe policy (floating, no focus steal). Do not open a GUI merely to prove a hash you already checked.
7. Gate axis-only mesh corrections on the pinned parent, identity linear world 3x3, and pinned translation, rather than demanding a full identity world matrix. A parent translation does not invalidate an axis tuck. Preflight every owned object before the first mutation and refuse rotation, scale, or shear.
8. Convert measured world targets with the inverse authored matrix, preserve untouched local coordinates byte-exact against float32 round-trip loss, and re-read the actual vertex afterward. Require unchanged transforms, no off-axis world delta, and the original axis-specific shift/clearance limits both after editing and after save/reopen.
9. Certify wall contact with raw and evaluated loop-triangle coverage over the complete recorded operand projection, clipped to the local wall-depth interval. Retain strict boundary slivers separately from the declared contact tolerance, and measure coplanar overlap by polygon union rather than summed triangle pairs. Tangential exits and bevel recesses are not through-openings; duplicate coplanar faces establish a z-fighting risk, not visually observed z-fighting. If no opening remains, preserve the candidate bytes and publish a hash-bound read-only receipt instead of saving or adding geometry.
10. Derive house-side measurements from actual saved walk-rim segments and the measured residence footprint, never a new cardinal cutoff. Distinguish longitudinal edges from terminal-cap normals; a normal facing the residence center may not separate its whole footprint. Keep endpoint and off-lot relations qualified rather than treating an algebraic sign as an approved planting slot.
11. Measure actual projected mesh faces with continuous edge crossings and two-way containment; do not bridge disconnected stones or plants with a convex hull. Inventory existing assembly roots and their components separately, preserving hidden legacy objects and unresolved identities without inferring species from asset names.
12. Exclude the measured object itself from ground-support candidates. Preserve ray witnesses and distinguish direct component contact from whole-assembly basal support, sampled coverage from exhaustive coverage, and strict threshold failure from numerical boundary ambiguity. If postprocessing removes a self-hit using already-recorded alternative hits, retain the original evidence and its hash; do not rerun a bounded Blender job to conceal the correction.
13. Gate outward-only coplanar corrections on volumetric burial before mutation. Certify a positive-volume inner box using closed consistently oriented loop triangles, an interior winding-number witness, and no boundary-triangle intersections with a tolerance-expanded box; a center point or overlapping AABBs alone is insufficient. Sweep the certified box through the complete allowed offset interval to test whether every translation remains buried, and quantify newly protruding side strips separately. Keep numerical translated-mesh trials distinct from actual scene edits and float32 separation distinct from visible z-fighting clearance. When the burial/no-lip contract blocks the move, publish an unapproved no-save receipt with unchanged authored-state signatures and original hashes rather than manufacturing a candidate.
14. For inward-only separate-infill recesses, distinguish the minimum representable nonzero separation from the minimum exceeding the established contact tolerance, and demonstrate that the immediately smaller coordinate step fails the chosen gate. Report a tolerance-scale rigid translation as numerical separation, not visual clearance. Prefer a rigid object translation that preserves every local mesh byte. Prove unchanged frontal projection, zero coplanar overlap, nonincreasing actual bevel exposure, and containment of newly occupied rear volume using a boundary-free connected-box witness; a global wall AABB alone does not certify no new lip. Preserve and quantify pre-existing numerical base slivers and bevel exposure instead of silently calling the whole infill buried. Repeat raw/evaluated proofs and closed-world authored-state equality after save/reopen, then publish byte-identical verified output without overwriting sources.
15. A request to see the scene is a look, not the reconstruction. Do not answer that look in prose and do not draw boxes on an orthographic plan. One unsaved frame of the latest candidate is enough, labeled with image generation in the local ComfyUI at /mnt/zer0models/comfyui (Union SDXL ControlNet, canny type) if they asked for generated labels. The server is not left running. Then return to the locked still. Do not keep the viewing job as the backlog when it cannot admit. Diagnostic plans stay measurement receipts. Hand-drawn overlays are not the picture they asked to look at.
15a. For several themed scenes matched to several references (one shared set, per-theme looks), follow `references/multi-scene-reference-matching.md`: finish one scene with the GPU lock while CPU-only critique lanes produce minimal change sets for the others, relay owner decisions by steering, handle soft references at matched resolution, and show comparisons as an HTML page in the user's browser.
16. Cut leaf cards only in the coordinate space the polygons were drawn in. A locked still with a different hash or pixel size is not that space. Do not stamp the polygons onto it until a verified mapping exists, and do not call unregistered cards a match.
17. Place an opaque print decal by intersecting camera rays with its actual supporting face, then offset toward the camera; separate constant-height back-projections can bury the decal inside the support. Preserve full planar UVs and isolate it from stone displacement. For small text, a camera-ray offset preserves screen registration while clearing displacement; normal offsets can shift the glyphs. Snapshot round-specific mutation modules alongside recipes so later edits do not silently change old renders.
18. Check the existing linked artwork's crop before inventing an asset or scaling by eye. A full reference image used as an artwork source can already contain the correct print contours while the material mapping crops the wrong pixel bounds. Rectify only the printed artwork into a run-local texture, remove mockup UI without directional fill streaks, and keep provenance explicit; never substitute a target screenshot for the rendered scene.
