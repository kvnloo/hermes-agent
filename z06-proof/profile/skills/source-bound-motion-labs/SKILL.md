# Source-bound motion comparison labs

## When to Use

Use for interactive motion/ephemeral-view prototypes that compare a faithful reference with creative proposals while binding only to existing read-only sources.

## Procedure

- Preserve the designated replica and operational worktrees/listeners with before/after HEAD, status and tracked-file hashes. Put the motion candidate in its own exact-base worktree and loopback listener; hand the process to the parent before returning from a subagent.
- Build an operator-purpose matrix before motion: question, actual source ID, exact fields, evidence boundary and unavailable behavior. Preserve reference geometry while replacing unsupported semantics with explicit unknowns. A worker-like row must be called a source binding when no canonical work join exists.
- Keep observed reference playback separate from creative proposals. Use fixed ring geometry as a category index, not fabricated progress. Animate the real selection-to-card-to-provenance binding, never invented execution or causal telemetry.
- Rebind the highlighted card to the selected source's actual field. Highlighting a merely related card with a different canonical source creates a false visual claim even when both values are real.
- Capture comparison A explicitly in memory; absence must remain absent in both text and ghost geometry. Compare identical field paths and snapshot times. A source-withheld hypothesis may remove evidence, but must not invent predicted outcome changes.
- Persist only deliberate, closed presentation recipes. Restore selection, disclosure, reading position and control focus without restoring revoked data. Keep controls mounted during refresh.
- Preserve upstream 401/403 through a fixed GET proxy and clear current/held data on denial. Treat transport outages separately as explicitly last-known. Drop held comparisons after per-source revocation as well.
- Verify native keyboard controls, reduced motion, playback, scrub, all selection bindings, Back/restore/pin/discard, cold/warm outage, denied access, private-field injection and storage denial in an owned headless browser. Never attach to the user's working browser for captures.
- Keep CSP intact when browser test helpers use prohibited string evaluation. Use bounded host-side state polling rather than adding unsafe-eval.
- Generate screenshots and video from real browser frames. Keep normal captures source-backed; isolate and label fault-injection payloads as tests. Verify gallery hashes and actual browser video decoding/playback before handing off.
- Distinguish working deterministic prototypes from voice/generation, meeting sharing, lifecycle promotion, accessibility conformance and decision-benefit/performance qualification. Do not claim the broader architecture from a successful animation demo.
