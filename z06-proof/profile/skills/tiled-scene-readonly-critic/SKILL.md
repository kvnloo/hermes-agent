# Read-only tiled scene critic

## Select the review scope first

Follow the owner's finite acceptance contract before applying the tiled protocol below. For an independent sampled repair review, compare the actual new rendered output with synchronized reference pixels; source changes, arithmetic overlays and passing tests are not visual acceptance. Do not expand a bounded review into a full grid, new renders, delegation or continuous-playback requirement unless authorized.

Close findings individually: a repaired material geometry defect can close while side-face appearance, slash phase or a separate nested-playback defect remains open. Give each residual its own severity, timestamp, exact evidence paths and finite recheck. Mark uninspected phases unobserved, not defective; sampled stills cannot certify continuous motion or whole-film acceptance. Distinguish parent-supplied output provenance from hashes or execution independently verified by the critic.

For sampled multi-layer geometry and lightweight raster measurement, use [references/sampled-render-repair-review.md](references/sampled-render-repair-review.md).

## Full tiled-review protocol

1. Load the authoritative dream-loop rubric and the owner's acceptance contract verbatim. Keep full-frame heuristic failures diagnostic only when the owner explicitly authorizes per-region pass/limited/blocked correspondence. Never manufacture a comparable total for a blocked region.
2. Lock original reference/capture hashes and the accepted-capture pointer. Assert equal aspect ratios before uniform LANCZOS alignment; never locally warp crops.
3. Inspect the reference to place overlapping semantic regions. Add a padded uniform grid whose unpadded core boxes cover every pixel exactly once; record masked fractions and explicit skipped tiles.
4. Build a white-is-ignore UI mask using stroke selection, not broad rectangles over scene content. Dark-theme contrast selection can miss dark ink on white themes: adapt polarity/blue-ink thresholds, review the mask overlay, and retain physical decals and poster crosshairs.
5. Use the explicit brief image budget: normally a reference-left/capture-right native crop pair, full paired frames with the same tile box, and the structure-overlay crop. When LOOK+CLEAR is required, add a bounded native CLEAR crop and disclose that protocol extension rather than replacing appearance evidence or silently calling the historical cohort identical. Keep original crops, delivered dimensions and image hashes in a manifest.
6. Use the requested provider/model with a separate one-shot CLI process per tile, bounded foreground execution and at most the authorized parallel count. Keep logs and a unique session ID for every tile; never resume or share a critic context.
7. Validate JSON identity, reference box, revision, category ranges, nullable blocked scores, exact total, one proposed change class and required fields. Retry failed critics only as authorized. Read back verdicts rather than trusting CLI exit zero.
8. When native Hermes session storage is available, inspect only the known task session IDs through read-only SQLite: verify actual model/provider, all brief-assigned successful vision loads, unique fresh sessions and verdict-only write targets. Inspect both PNG IHDR and JPEG SOF headers in stream payload prefixes; transport can differ by image, and truncated payloads are not complete image files. Do not export unrelated session data or model configuration secrets.
9. Aggregate with Python: per-tile scores, diagnostic category means by layer, worst tiles, deduplicated issue groups with exact source-gap evidence and citing IDs, and preserve wins. Define severity explicitly, e.g. distinct citing tiles times mean total-score deficit. Overlapping crops are not independent votes or a global acceptance score.
10. Reject unmeasured numeric critic recipes as implementation facts. Critics may mix full-frame and enlarged-crop coordinates, misstate colour temperatures, or contradict one another on fill and light size. Preserve raw verdicts but aggregate the supported visual target and flag disagreements. Do not infer emission or albedo from lit colour alone, and do not deform canonical geometry to fit painted inconsistencies.
11. Visually inspect the worst-eight contact sheet, verify grid coverage and protected-input hashes, then generate and verify SHA256SUMS for all output artifacts. Report completion counts and major gaps, not a replay of the procedure.
