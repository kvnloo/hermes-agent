# Regional optical-softness trials

- Freeze parent/reference hashes and protected object/material/world/view/camera signatures. Keep CLEAR distinct from LOOK; label inherited CLEAR instead of implying a new render.
- Serialize heavy renders under the project render lock, with separate GPU admission when required. Never interfere with unrelated workloads or retain a superseded load gate.
- Test native-density upper/rear/foreground coupons, an already-soft bokeh safeguard, and protected subject edges. Reject broad radii that enlarge existing soft lights even if aggregate target distance improves.
- Use cropped compositor bounds for economical exploration. Remap screen masks from master coordinates into crop coordinates. Reproduce Blender float32 border products and check actual PNG dimensions/origin; never resize real pixels to satisfy erroneous metadata.
- Compare methods in the same cropped/full-canvas mode. Fog Glow and other frame-relative operations differ between coupon and full-frame modes; always verify the final full frame.
- Instrument recipe and render stages before declaring silence a hang. Preserve interrupted trials and distinguish operational from optical failures.
- When only one region wins, preserve the parent's pre-glow subtree outside a feathered mask, then apply one shared final Glow. Do not blend independently bloomed images and accidentally enlarge protected halos.
- Preserve exact pre-repair source for earlier experiment receipts instead of attributing their images to subsequently edited code.
- Save and reopen the selected scene, verify protected state, then render the saved graph without rebuilding it. Audit reachable Glow count and image-reference availability; availability is not a decoded-pixel hash audit.
- Inspect native regions and full hierarchy. Obtain fresh anonymous side-swapped judgments using owner preferences and protected-region sheets; decode only afterward.
- Separate preference from approval. Both orders can prefer a candidate while mask seams or depth inconsistency still require review HOLD. Leave production pointers unchanged when acceptance gates fail.
- Report regional descriptors and protected pixel deltas without claiming to recover a physical PSF. Disclose renderer/device differences; identical scene data does not guarantee identical image patches.
