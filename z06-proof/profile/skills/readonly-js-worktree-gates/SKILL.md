# Read-only JavaScript Worktree Gates

## When to Use

Use for exact-SHA test/build assignments where tracked sources and a protected working branch must remain untouched.

## Procedure

1. Read the assigned runbooks, package scripts, test configuration and build script before installing or running. Verify every supplied full SHA and record initial Git status, tracked diff and index identity. Do not create, reset, clean or advance worktrees.
2. Select an already available Node version satisfying the package engines; record exact Node/npm versions rather than silently using a newer default. Disable required telemetry and npm lifecycle scripts, use a task-owned npm cache and scratch TMPDIR, and keep tests away from live profile/config paths and GUI endpoints.
3. Install locked experiments with `npm ci --ignore-scripts`; install an unlocked frontend with explicit `--ignore-scripts --package-lock=false --workspaces=false --no-audit --no-fund`. Keep installs inside the assigned worktrees. No root install or manifest rewrite is implied.
4. Persist each command's argv, cwd, SHA, environment overrides, exit, deadline and complete output before running the next batch. Retain original failures when retrying. Parse test-runner summaries and enumerate JSON assertions; do not count overlapping focused/full rechecks as separate unique tests.
5. Diagnose setup failures independently. An npm Arborist peer-set crash can be tested with a different already installed npm under the same Node and identical flags; do not claim the application was fixed. Record both manager versions and the resolved package trees.
6. When sibling workspace source cannot resolve an isolated package's dependencies, prove the resolution error first. If permitted, add a task-owned ignored sibling node_modules link to the installed dependency tree, refusing to replace any existing path. Do not externalize missing imports or alter production code merely to make a bundle pass.
7. Preserve canonicalization failures. A raw symlinked TMPDIR can break a test that compares realpath output with its fixture path. Retry using the discovered real path of the same scratch directory, while retaining the failing run and reporting the portability gap.
8. Check compiler-version contracts. TypeScript 6 explicit-file invocations may require `--ignoreConfig`, and Node targets may need `--types node`. Run the original command first, then label any CLI-only adaptation; a passing adapted check does not make the committed workflow green.
9. Build to task-owned output and syntax-check the result. Do not execute an entry bundle if that would launch a GUI or connect to live services outside the assigned lane.
10. Separate real parser/SDK tests, injected capture transports, stub-renderer logic and actual native-window/pixel evidence. Review real command routing and missing-plugin fallback separately from helper tests. Never turn mock transport success into a screenshot or human-inspection claim.
11. Finalize only after rechecking exact SHAs, tracked diffs/index state, protected refs and output/log hashes. Report final passing checks alongside unresolved stock-command failures, setup adaptations, coverage gaps and precise artifact paths.
12. Resume interrupted verification from saved receipts before rerunning tests. Inspect each manifest and command-index envelope before iteration: one wave can use path-keyed JSON objects, arrays of records, and text SHA256SUMS. Read and archive any report that will be replaced, rehash every retained log and JUnit/JSON result, recount individual outcomes, and bind them to unchanged source/index and bundle identities. Reuse complete matching runs; keep recovery/audit counts separate from test counts and do not relabel historical exits as freshly executed tests.
13. When hard-linking donor dependencies, inspect the donor directory itself for a symlink first: `cp -al donor/node_modules destination` preserves a root symlink. Use `cp -al donor/node_modules/. destination/node_modules` to copy the referenced tree, verify the destination is a real directory, and compare a sample file inode. Never install or rewrite shared hard-linked package files.
14. Distinguish read-only donor reuse from a locked installation: matching direct dependency versions does not establish transitive-lock equality when the donor lock differs. State that limitation with the actual runtime versions and keep focused proof narrower than canonical full-gate qualification. When auditing git archive snapshots, account only for line-ending conversions explicitly required by tracked attributes; never blanket-normalize tested files to hide byte differences.
15. For CPU-only browser qualification, inspect each harness launch policy; `GPU=0` is not a universal Chromium switch. Use a task-local Playwright preload to force headless software rendering without changing app/assertion sources, and record CDP `SystemInfo.getInfo` renderer evidence. Preserve original harness failures, including source-regex config detection bugs; explicit scene-tier overrides must match the effective asset policy, and an owner trace replay on a different scene is not device evidence.
16. Prove terminal fallback in separate layers: an owned credential-free PTY with no terminal-protocol reply can establish the real entry's NO_TSP exit and terminal restoration; mocked launcher contracts establish branch routing only. Neither proves the full Python-to-Ink handoff or native UI lifecycle. Reconstructed immutable Git streams can corroborate omitted historical output hashes, but must remain labelled as fresh reconstruction rather than recovered raw logs.
17. Review process/socket lifecycle fixes with exact original/candidate public-API executions, not only green fixtures. Add bounded controls for stop-before-spawn-error, protocol rejection with a child that ignores SIGTERM, and malformed input after all requests settle; distinguish introduced regressions from inherited defects. A persistent dispatcher changes the idle-input attack surface. Run crashing controls in owned process groups and reap their descendants, because uncaught parser exceptions bypass JavaScript cleanup. Real child processes and Unix sockets establish transport/lifecycle behavior, not compatibility with the real external executable.
17. For final-read cancellation qualification, use a native ReadableStream with highWaterMark: 0 so speculative pulls cannot move the abort before the intended read. Preserve a caller-owned abort reason by identity, assert the reader lock is released, and include healthy, chunk-abort and byte-cap controls. Run the identical probe against the owner's source and an in-memory post-read-check removal; label browser-native stream execution separately from application UI, renderer and live-provider acceptance.
18. When comparing a base module through head dependencies, call it a base-source overlay rather than a full-base execution. Record the original blob, import rewriting and unchanged dependency closure; prefer in-memory variants so baseline and mutation controls cannot dirty a concurrently running exact-head gate.
19. For high-refresh browser qualification, report the observed rAF cadence separately from the target frame budget and requested input cadence. A 60 Hz headless/SwiftShader run compared against 8.33 ms is not 120 Hz presentation evidence. Event Timing samples are lab interaction timings, not field INP; event-to-rAF excludes dispatch and physical presentation delay. Preserve contradictory results from different gesture harnesses rather than averaging incompatible HQ definitions.
20. Freeze the behavioral goal as well as the SHA before runtime qualification: an unrelated PR can build and exercise a real component without qualifying the requested plugin implementation. Reconcile original owner packets and all live reviews against the current diff; resolved threads can describe repairs removed by a later scope-trimming commit. Replay the owner's removed tests against current modules and a clearly labelled pre-trim module overlay with lock equality verified; do not infer whole-base acceptance from the overlay. Honor a repository's mandatory browser surface: if its runbook forbids fallback and the required panel tools are absent, stop browser verification rather than substituting an external harness. When an allowed full-app authentication gate blocks an exact-head React runtime gate, preserve the real app URL, auth/transport failures and screenshot before testing a separately bundled import of the real component. Label controlled inventory, scope state and callback sinks explicitly; rejected submit admission and a fixture interrupt are not successful provider send/cancel. Exercise native editor/menu events, then capture the actual mounted production callback for stale-ref tests. Mutation-remove the real guard only in a compile-time owned variant, require the same assertion to fail, and reload the unchanged baseline to pass. Place raw-source mutation transforms before React compiler transforms, otherwise a missing source pattern is a harness error rather than a killed mutation. Count only browser commands with returned executed assertions: a string containing an uninvoked function can produce a successful automation call without running the test. Stop tracing through the browser's own command path and validate the ZIP central directory/CRC before copying it; copying immediately after a process-group kill can retain a truncated trace even when the original finishes later. Preserve the partial trace and produce a separately labelled verified replay.
21. Keep frozen baseline exports outside source trees: lint tools can traverse arbitrary renamed build directories and report thousands of generated-code failures. For static responsive-image changes, verify actual browser currentSrc and decoded resource dimensions across DPR profiles, original-link byte identity, full no-JS content behavior, and deployed footprint as well as transfer savings. Next Image unoptimized does not supply responsive candidates merely because sizes is present. Reject offscreen containment candidates that pass a focused skip test but fail established content/interaction gates; do not weaken text assertions to manufacture a performance pass.
