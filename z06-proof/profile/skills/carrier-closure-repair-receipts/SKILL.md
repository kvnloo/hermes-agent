# Carrier closure and repair receipts

- Read current policy/directory/queue snapshots before interpreting historical work; current GitHub-only authorization supersedes retired approval-system text, but never clears a denied action.
- Seed every explicit user target as well as directory, registry and historical carriers. A graph fixed point alone is insufficient: numbered prose and bare `#N` mentions may never become explicit graph edges. Assert a per-user-item coverage matrix.
- Paginate all conversation comments and assert collected count equals declared total. Save raw responses and make checkpoint writes atomic. Distinguish conversation coverage from PR review/inline-thread coverage.
- Deduplicate exact carrier identity separately from historical rows and artifact URLs. Preserve author/envelope/source/head/evidence/next gate/disposition fields; label unknown identities explicitly. Linked carriers do not prove mechanism equivalence or create new ready contributions.
- Preserve unresolved bare references and malformed literal tokens without repairing them. Keep excluded personal projects and terminal origin-context edges in an auditable edge ledger.
- Mark historical fallback queues read-only when current policy requires project-local routing. Missing current queues are coordinator handbacks, not permission for child issue creation.
- Reproduce each defect independently before changing production code; replay the original published probe unchanged against baseline and candidate. Omit each fix in disposable copies to show its regression detects the defect.
- Verify local delivery bundles by restoring into fresh repositories and rerunning committed-head official suites. Record original carrier head separately from unpublished local candidate head and precommit dirty-tree receipts.
- Audit hosted scientific artifacts using actual raw outputs and pinned source fixtures; separate artifact replay from new native solver execution, and preserve topology/calendar/measurement limitations.
- Prepare unsent, hashed payloads with exact targets and parent-scope prerequisites. A denied result cannot be republished on another queue to bypass the denial; claim timestamps are not evidence that a remote executor has stopped.
- Report independent review and authorized native acceptance as pending when not performed. Local pass counts, an installed service, and stale claim prose never substitute for those gates.
