# Locked Blender continuation

## When to Use
Continue a reference-match loop with locked geometry/camera, independent round judging, and a structure gate.

## Preserve the experiment
- Read the run policy and kept/rejected verdicts. Branch from the last **kept** recipe, not the newest capture.
- Snapshot mutable helpers and asset dependencies per round. An edits JSON importing evolving shared code is not reproducible.
- Hash the locked target before/after. Never overwrite approved donor blends; save new run-local scenes.
- Hash protected mesh vertices, faces and world matrices and locked camera state before/after mutation. Verify expected object count and equality across rounds.
- Use background Blender and the existing GPU lock.

## Judge and promote
- Replace an unavailable judge only with owner approval. Calibrate the replacement on a historical kept round, preserve the original rubric/verdict and report score drift.
- Follow the authorized review protocol. For history-calibrated judging, give target/current/previous-kept captures and verdicts plus gate evidence. For fresh blind A/B judging, score both parent and candidate against the target in the same session, randomize anonymous left/right labels, then repeat in a fresh session with sides reversed. Supply no prior scores, identities, edit hypotheses or verdicts; disable injected project history. Bind both reviews to exact image/prompt hashes and preserve the private decoding outside judge inputs. Explain if a delivery sheet uses a historical anchor rather than the previous kept round.
- Treat a structure gate as PASS/FAIL unless the owner explicitly requires numerical nonregression. Small denominator or worst-tile changes inside PASS are not failures. Promote only under the authorized visual rule; for strict swapped blind A/B, require preference or tie in both orders with no flagged candidate regression. Do not average cross-session absolute scores or use a new judge to fish away an unfavorable result.
- Request original-resolution crops; full-frame vision may downsample critical print/edge details.
- Keep one change class per round. Isolate a promising label repair from a failed massing bundle before promotion.
- Resolve explicit conditional-keep requirements with real tests. Preserve rejected trials and noise probes; do not treat worst-tile edge pixels as a count of failed tiles.

## Planar artwork
- Inspect linked source artwork and the actual support plane. Never bake target scene pixels into a texture.
- Intersect locked-camera rays with the supporting face, then add an opaque planar decal with small clearance. A guessed depth plane can bury the decal or wrap it over corners.
- Preserve continuous source halftones during duotone correction; binary thresholds can create contour errors. Record source hashes and palette derivation.
- Transport registered labels onto changed supporting geometry without altering their projected layout. Change text, size or shear in a separate artwork round.
- When porting registered decals without moving their supports, measure the receiving face bounds as well as the infinite-plane intersection. A perfect screen-space quad can overhang the unchanged stone; report that support deficit explicitly rather than calling it a completed geometric fit. Suppress detached cast shadows from offset ink meshes, and preserve the pre-fix render when checking this artifact.
- Before porting a UV correction between scene generations, inspect the reachable shader coordinate source. A new isotropic UV layer is only staged metadata if the sibling still shades from Object/Generated coordinates; do not silently replace its theme-specific stone shader with the donor's PBR material, and do not claim a visible texture-density correction.
- Check image projection as well as coordinate links when activating a metric UV layer. BOX projection fed by 2-D UVs drops an axis on some faces; explicitly use FLAT for the UV-driven image samples and verify the saved node properties before rendering.
- Preflight actual sibling stone meshes and object inventory, not the handoff's claim of shared geometry. Missing prerequisites and different raw meshes must be reported and resolved within authorized scope before claiming a locked-shape port. A script rerun may differ through Boolean ordering or bevel wear; compare topology, UV hashes and transforms against the approved checkpoint.
- Copy the requested object-name list when assigning `library_load.data_to.objects`: Blender replaces that list's entries with Object references. Do not rely on an unlinked imported object's unevaluated `matrix_world`; use a verified source transform, and preserve an already-equal recipient transform rather than reassigning it through decomposition.
- Check image bounds after native-pixel artwork shifts. An upward shift can sample beyond the source bottom and make EXTEND repeat one row into visible streaks. Add reflected source margins, verify consecutive-row variation, and inspect the native final-frame strip before promotion.
- Treat judge colour hexes and coordinates marked approximate as hypotheses. Use measured palette quantiles and projected landmarks before repainting or moving a corner; keep the judge's raw verdict and document factual corrections separately.

## Gate discipline
- Treat judge coordinates with their stated uncertainty. Check actual pixels and back-projected landmarks before chasing a suggested 5-pixel correction: bright bevels and shadows can impersonate edges.
- Attribute residuals through read-only, disjoint image regions and reconcile counts with gate JSON. Diagnostics do not authorize replacement masks or prove semantic causes.
- Report a gate blocked by locked geometry. Never silently relax thresholds, masks or camera locks, or enter a gated material pass.
- After an owner-authorized subject exclusion, derive the mask from the locked evaluated geometry/camera, apply the fixed dilation, and rerun every known-answer case. Require all non-exempt must-fail cases and all must-pass cases to retain their classifications. Re-gate the previous kept render with the same mask before comparing scores; a new worst tile may remain a real blocker.
- Before a cross-theme shared-set sync, compare actual pre-change geometry and modifier stacks, not only object names/transforms. A sibling can still contain eight-vertex boxes and omit the donor's cluster meshes. Record missing common prerequisites explicitly; do not claim a direct-transplant precondition passed. Replayed BMesh wear/booleans can differ by sub-millimetres and topology, so compare raw and canonical geometry/UVs against a locked donor rather than treating script completion as lock identity. Preserve the failed replay evidence if the authorized delivery uses the frozen canonical mesh.
- When a shared receiver mesh changes, re-seat existing approved lettering by its preserved camera rays before rendering. Verify native labels remain fully readable and measure screen-coordinate drift; a geometry/robot guard alone will not detect ink buried inside the new support. Hide superseded source frame/step geometry when its replacement cluster is introduced.
- Adapt anti-tiling to the receiving theme's actual shader topology: a procedural stone with one repeating height image is not the donor's four-map PBR material. Keep theme colour/procedural branches, operate on the existing repeating signal, and state which channels and UV source were changed.
- When an owner supersedes a cross-theme port with a new locked artwork/material donor, quarantine the earlier beauty evidence, transplant the new donor's UVs and complete detail graph, and rerender before judging. Calibrate saturated theme lighting with an albedo-only HSV node and read its saved numeric values back; reference RGB is a lit target, not a directly reusable albedo. Preserve the original normal/roughness/height image hashes and graph connections.
- Measure texture density after final massing edits. UVs authored before resizing a stone can stretch anisotropically even when the shader still says a fixed tile size; compare world edge length per UV unit independently along U and V. Repair an authorized planar-face mapping with orthonormal world-metric axes at the original tile scale, retain a measured phase anchor, and assert every non-target UV loop remains byte-identical. Allow only quantified micro-relief error in the world-length audit.
- Overlay projected authored/evaluated contours before acting on a judge's repeated edge diagnosis. A cast-shadow band well inside a top-face polygon is not a duplicate front arris. Split a glass sphere's internal optical residuals from its silhouette/rim residuals; do not claim the entire failed tile is nonstructural when the actual silhouette still differs.
- Fit visible slab boundaries from native image gradients and extrapolate occluded endpoints instead of trusting approximate target coordinates. Keep the measurement receipt; a few-pixel move in the wrong direction can create a new worst tile.
- Test shared-yaw hypotheses against the locked camera horizon, not similar screen slopes. Lines at different image heights can have matching slopes yet require different world yaw; report incompatible vanishing points rather than forcing warped boxes.
- Couple rigid-box reprojection fits to nonpenetration and visibility constraints before rendering. Matching infinite projected arrises does not ensure that those arrises remain visible; floor/contact-height constraints alone can leave large box intersections and extra exposed tread faces. Distinguish hidden authored core-edge residuals from visible contact boundaries.
- Preserve strict decal planarity by offsetting the supporting plane and intersecting camera rays with that parallel plane. Subtracting one constant distance along differently angled rays preserves screen registration but generally warps the resulting quad.
- Check tread planarity and overlap before remodelling a patchy-looking surface; lighting can cause the patchiness. A four-vertex face is not proof of planarity: measure the fourth vertex's distance from the plane through the first three in world coordinates. Unequal corner heights and nonparallel edges can create a triangulation wedge.

## Optical and material diagnostics

- Test compositor Defocus on a one-pixel HDR emitter before relying on a zero blur cap. In Blender 5.2.2 an explicit `blur_max=0` bypassed useful blur; a positive cap produced a spread disk. Preserve failed candidate captures, repair under new variant IDs, and scale a positive cap and any thin-lens CoC by the actual master width before building the graph. Check protected foreground sharpness independently of background blur.

- Resolve the render-visible object's actual material slots before a shell-material pass. A material named `PHOTO-pigment-head` can shade only the lower shell while an eye-rim repair material owns the entire upper/back shell. Audit receiver assignments and reachable outputs, not material-name semantics; otherwise two apparently valid shader trials can leave the named blocker untouched. Preserve this routing diagnosis if the trial budget is exhausted rather than silently adding an unjudged third candidate.

- Diagnose missing emission through global exposure as well as shader constants. A large negative exposure can suppress intact inlays while compensating key lights keep shells readable. When exact donor emitter and label constants are locked, an explicit radiometric normalization can restore donor exposure and inversely scale non-target lights/world/emission, preserving the original emitter inputs. Guard camera-only non-glow fills separately, disclose the global integration dependency, and judge the restored indirect blue spill rather than claiming all protected pixels are unchanged.
- Compare serialized Blender graph receipts canonically: JSON turns tuples into lists, so hash canonical JSON rather than comparing a live tuple-based graph directly with a decoded receipt. For appended text objects, audit the font filepath/content rather than volatile datablock suffixes; retain exact mesh, text, transform and shader checks.

- Preserve decal compositing when darkening robot mechanics. Edit the substrate ramp/mix and reachable roughness range rather than disconnecting Principled Base Color: the final link may carry servo labels as well as metal colour. Verify image bytes and native joint crops after reopening.
- Port shared DOF and foliage separately from optional stone grading when themes already have accepted stone recipes. Snapshot the shared helper and explicitly bypass its stone branch; allow a judged per-theme aperture adaptation when foreground pores or portrait halftone lose clarity.
- Compare replay pixels numerically without promising byte identity. Saved-scene OptiX renders can show small differences; record mean/max channel error and source hashes, retain both renders, and distinguish near reproduction from exact equality.

- Measure foreground and portrait sharpness as well as background Laplacian energy when enabling physical DOF. An arch and a sharp portrait can occupy effectively the same depth, so matching one focus plane cannot guarantee both. Report the tradeoff instead of calling a preferred DOF trial a complete focus match.
- Preserve inherited selective-focus ownership when replacing foliage: inspect the compositor's object-index masks and assign only the new plant objects to the intended foliage index. Never renumber existing objects. Distinguish physical camera blur from inherited compositing blur in the shared recipe.
- Diagnose hard-eroded selective-blur masks separately from alpha-mode bugs. Full-image blur mixed through an unfeathered eroded object mask can leave a broken sharp boundary and import foreground colour into the background. Receiver-normalized convolution plus an inward visibility-clipped feather can remove that fringe, but may leave a rear silhouette too sharp for its softened interior; require native edge review before promotion, and switch to actual depth/layer optics if that inconsistency survives.
- Verify grain across spatial bands after optical softening. Re-adding the original high-pass band after blur can match a CURRENT patch's fine-grain RMS while still losing broader print mottle. Calibrate from current measured statistics, preserve the unit-gain intermediate, and never overrule a native texture regression using a single high-frequency metric.
- Separate source-frequency restoration from silhouette diffusion: restoring G3-minus-G10 mottle can also restore a hard edge. Feather residuals using real depth discontinuities, but do not assume a blurred depth-band mask makes a hard visibility/ID gate antialiased. An outward depth gate can expose serrated near-block fringes despite softer rear edges; require native occluder-boundary review and hold any such regression.
- Attribute selective-focus receivers with projected bounds and native crops, not names such as front/rear. A raised rear block can be the nearer visible block beneath foliage, while a front block is the farther centre-left receiver. Preserve misattributed trials as implementation failures; verify both the protected near block and the softened far block before paying for another swapped review. Whole foliage ROIs can include stone, so a sharpness drop there does not prove leaf softness changed.
- Re-measure chroma as well as lightness when lightening a pale pier. An apparently cool dark region can already be too yellow in measured Lab; a warm RGB gain can fix L* while worsening hue. Use a bounded measured-channel correction on the same material-local regional mask, then re-render and measure rather than treating the gain estimate as proof.
- Preserve downstream random-generator state when selecting a procedural component subset. Skipping an earlier rejected growth loop can silently randomize later dew or scatter geometry. Execute the original loop and discard only its serialized output, or isolate independent random streams; verify retained geometry and top-hair/radius prefixes against the original saved scene.
- Register component-review ROIs to their actual raster size before measuring integration gains. A half-resolution source cropped with full-resolution coordinates returns wrong or black regions. Record native dimensions, distinguish resampled tone evidence from native detail, and do not compare Laplacian sharpness after upsampling as though both captures were native.
- Preserve light-link receiver membership when replacing a combined foliage mesh with a cropped copy. Copying transforms, materials and pass_index does not copy membership in the original lamps' receiver collections; unrelated retained ferns can become dark despite passing geometry/material guards. Link the replacement to the original receiver collections, then inspect a full-frame replay, not only the edited crop.
- Use float-preserving smoothing and bilinear height lookup for baked portrait grids. Integer truncation of nominally exact UV grid coordinates can repeat/skip rows because of floating-point rounding; more subdivision alone does not fix the resulting terraces. Judge stone weathering separately: smooth anatomy can still read as plaster.
- Judge curtain placement from projected head contours, not a near-vertical UV stripe. Dense repeated star-shaped leaves and uniformly catching tips can still miss small natural ivy; maintain crown continuity and inspect lower embedded-bead coverage at native pixels. Count reduction alone does not establish blue halo quality.
- Separate contour correctness from canopy coverage: a measured height-boundary route with rounded leaves can still regress a thick curtain into a narrow garland. Judge the semantic cheek/jaw silhouette, canopy width/depth, and moss coverage across curl surfaces independently; do not cite instance counts or segmentation receipts as visual acceptance.
- Under a locked shared Fog Glow, test smaller high-radiance bead cores with varied intensity rather than enlarging pale emissive discs. Inspect blue halo pixels separately from white-ish cores and preserve the compositor/exposure owner; improved halos do not excuse regular fairy-light placement.
- Diagnose saved-scene guard differences before changing tolerances: Blender can drop pre-existing zero-user materials at save. Probe their actual baseline user counts, retain the failed receipt, and exclude only proven absent unused datablocks—not active materials or unexplained graph changes.
- Judge luminance-derived relief and learned monocular depth independently on printed portraits. Both can regress anatomy: luminance produces terraces and inferred depth can interpret artwork as a tilted plane. Preserve the original registered UVs with camera-ray displacement, confirm depth near/far convention from the actual renderer, and retain rejected depth trials rather than claiming learned depth is automatically better.
- Use normalized values for Blender shader Bright/Contrast nodes and render a bounded albedo check before a full grade. A contrast value intended as percent can create albedo above one and dramatically increase indirect scene illumination despite unchanged lights.
- Invert registered artwork UVs piecewise through actual mesh triangles when measuring a dolly-zoom print panel. An affine UV-to-world fit across a stair can have centimetre residuals; require unique supported barycentric corner hits, report clipped corners, and measure silhouette/background drift even when robot projected height is held fixed.

- Gate visible facet-tone structure separately from UV-transfer correctness when replacing a full-face printed stone mesh. A replay-stable angular triangulation can preserve the artwork yet shade as a nearly black sheet; adding working microcatches then produces a starfield rather than wet faceted stone. Keep the integrated candidate on HOLD when native side-swapped reviews prefer the parent's readable body, even if moss, ink clearance and catch size improve.
- Weather the active stone branch on printed faces, not just the unprinted material slots. A full-face artwork material can leave the visible front clean while its top changes. Insert dirt/moss colour before the artwork mix's stone input, retain its image/UV/alpha and ink input, and exclude ink alpha from added roughness/coat layers. Verify the reachable compositor and native front crop before judging.

- Attribute a glass hotspot with real glossy/transmission passes and sphere-only direct-light exclusions before changing global lighting. Cycles glossy-direct includes environment illumination; a hotspot surviving exclusion of every direct lamp can still be HDRI-driven. A zero-energy Bounce lamp cannot explain it.
- In Blender 5.2, set image settings `media_type='MULTI_LAYER_IMAGE'` before selecting `file_format='OPEN_EXR_MULTILAYER'`. Read EXR subimages as well as channel names; the first subimage may contain only the compositor result.
- Check Cycles indirect sample clamping before increasing emitters seen through glass. Transmission paths are indirect; a low clamp under strongly negative exposure can suppress both veins and sparkles regardless of their shader strength. Raise it in a bounded preview, record the global render-setting change, and distinguish brighter transmitted light from collateral indirect highlights elsewhere.
- Test the glass-envelope regression when bypassing indirect clamping with transparent/reflection hybrids. Unrefracted transparent rays hitting an inward Fresnel boundary can trigger a dark total-internal-reflection disc; a facing-based blend avoids that artifact but is an optical approximation and can lose convincing refraction or silhouette. Judge the shell independently rather than crediting the brighter interior as a complete improvement.
- Judge volumetric Voronoi membranes by rendered material appearance, not cell/face counts. Weakly lit transparent walls can still read as an edge graph; stronger linked sheen plus high opacity can turn them into opaque foil. Preserve those failed optical trials and qualify sheet translucency, dark gaps, core hierarchy, and glass envelope separately before promotion.
- Package light-linked components without their external receivers. Temporarily detach scene-stone receiver collections before writing the asset library, restore preview links afterward, and reconstruct links to the recipient scene in the idempotent importer. Otherwise an apparently isolated orb library can silently carry the entire stone environment.
- Raycast the actual receiving ledge before tuning a magical pool light. A source beneath the sphere can illuminate mostly occluded stone; a forward-shifted point can instead bleach the front face. Place a downward spot just above the visible top inside the ledge footprint, and inspect the rendered top and face separately.
- If the owner explicitly requests target-image-assisted interior projection, label it as view-dependent reconstruction rather than geometric recovery. Register UVs by tracing locked-camera rays through the actual dielectric boundary onto nested internal surfaces; mask/inpaint photographed envelope streaks so they do not double the retained glass rim. Report hero-view metrics separately from depth/optical acceptance, and keep the procedural alternative. This explicit authorization is an exception to the default prohibition on baking target-scene pixels.
- When replacing a light-linked interior mesh, rebind its linked illumination to the new owned receivers or disable now-irrelevant interior lamps. An emptied receiver collection can expose a bright area-light rectangle on the retained glass, confounding a pattern comparison. Guard shell/rim/spill independently, and retain the failed trial.
- Audit spatially overlapping legacy orb objects as well as the current component namespace. A later source scene can retain an independently named emissive curve that survives an older replacement allowlist and becomes magnified by a new solid-glass envelope. Hide only owned internals in a diagnostic first, identify surviving contributors by world-space bounds, and disclose them; do not silently change a judged candidate after its round budget.
- Before claiming a restored glowing orb, inspect the reachable emission-strength link as well as its procedural nodes. A retained network can exist while its final strength socket is disconnected and zero. If material preservation forbids repair, report the dark-core limitation rather than crediting added rim lights with restoring internal emission.
- After reconnecting an orb, inspect native-pixel optical appearance: dense noise-warped Voronoi can read as purple scribbles, while an opaque emissive core can read as a flat wireframe lamp. Qualify reachable surface emission, volume absorption, refractive cell shading and outer reflection separately; preserve intermediate captures rather than equating a connected socket with target-like glass.
- Treat larger/brighter growth and target-faithful morphology as separate criteria. Enlarged umbrella-cap donors can satisfy a requested cluster-size change yet regress against arrow-like reference sprouts; keep blind-judge regressions explicit and do not promote a net-preferred candidate under a no-regression rule.
- When excluding small growth from a sloping printed panel, test projected convex hulls against the actual panel quadrilateral. Axis-aligned print bounds include empty space above its diagonal top edge and can falsely reject safely seated tread growth; retain the coarse-test failure and replace the geometric approximation, not the clearance criterion.
- Label a material-local reflected-environment lookup plus true refraction as an artistic optical approximation, not a physically identical glass shader. Preserve the original HDRI/world and independently judge missing windows, smeared highlights and rim changes before promotion.
- Re-measure tone for each kept candidate. Do not carry a rejected predecessor's median into the next verdict: coat and normal changes can change exposure without changing the albedo map. Compare shadow quantiles as well as the median.
- Treat light linking as direct-receiver isolation, not proof of unchanged protected-subject pixels. Measure an eroded protected silhouette against the locked baseline. Test added-light Cycles `max_bounces=0` when secondary transport matters; preserve the original lamp/world/material guards and judge the isolation trial separately.
- Serialize vector/color shader socket values as numeric tuples, never `repr(bpy_prop_array)`: Blender's repr can identify the property without exposing changed values. Serialize ID-valued Geometry Nodes sockets by datablock type/name and independently hash their unlinked prototype geometry; object repr embeds process pointers and creates false rebuild failures. Exclude volatile `session_uid` from reopen comparisons, not physical light properties. Execute mutations in a separate namespace so a material variable cannot overwrite the audit's material-serialization function.
- Integrate negative-exposure components after the glow owner's normalization, then convert only newly authored lamp/emission radiance. Convert indirect clamp thresholds into the same radiance units, unless the selected asset explicitly removed that dependency. Detect native exposure adapters before scaling: geometry color attributes can carry emitter energy, so double-normalization can extinguish an otherwise valid orb. Measure native source-review ROI luminance before applying bounded component-local gains; keep one compositor bloom owner.
- Attribute integrated ledge changes against the stone lane's review as well as glow/orb reviews. A sparse or smooth ledge already present in the selected stone component is a carried component defect, not proof that integration lost geometry. Preserve the original judges' exact image inputs when correcting comparison-panel attribution; do not silently relabel revised evidence as previously judged.
- Supply independent judges with explicitly labeled target/current native crop panels when per-image reload limits prevent all requested regions being inspected. Preserve incomplete verdicts, mark their missing views, and obtain a fresh complete review without prior scores. A history-calibrated score and a no-history absolute score are different evidence; report their disagreement rather than silently replacing either.
- Do not average independent PBR phases across crisp foreground pores merely to suppress repeated pale stains. That can halve pore contrast and create muddy double pits. Isolate a successful distant-arch treatment, or separate low-frequency stains from the original high-frequency pore field.
- Prove cap/bevel ownership with a temporary emission-ID render before tuning bright rims. Strong cap attenuation can exchange a white hairline for a dark seam; neither is automatically a correct soft stone edge.

- Render production beauty before assigning semantic diagnostic object IDs. Existing compositor ID masks may silently blur or recolor newly renumbered objects; render the object-index diagnostic separately with compositing disabled, and quarantine/rejudge any beauty produced with diagnostic IDs.
- Validate Night stone morphology at native resolution before crediting scan provenance. A real PBR rock scan can still read as long-veined shale when the target is wet granular basalt; distinguish binder brightness, aggregate scale, cap normals and moss microtufts instead of repeatedly increasing generic bump.
- Compute a wet-surface reflection source from the actual hit normal and camera direction, then isolate the recessed binder from reflective grains. A correctly positioned source can turn a rough binder into silver concrete; inspect native face/cap crops and measured luminance before promotion.
- Audit protected robot state cumulatively against the original scene after authorized print-only emission exclusions. Preserve every original node value and texture pixel, whitelist only the demonstrated mask-link additions, and do not treat a broad per-material guard exemption as proof that actual inlay strength stayed unchanged.
- Report replay pixel deltas rather than silently relaxing a failed equality assertion. Saved-scene OptiX/denoising renders can differ by rare one- or two-level channel values; retain the failed exact-equality result, maximum/mean delta and changed-pixel fraction.

## Reference-to-material and deep-zoom qualification

- Approve one recognizable material or botanical exemplar before multiplying it across the scene. A wrong moss shoot remains grass-like after denser scattering; separate canopy coverage, individual morphology and illumination gates.
- For camera-projected greenery masks, cast weighted samples against the actual receiving geometry, subtract adjacent-lane masks, and reserve locked label/contact regions. Record root positions and projected coverage separately from rendered foliage coverage: a normal offset changes projection and a correctly placed instance can still be a coarse, spiky moss exemplar. Never treat target-mask registration or root counts as native-fidelity acceptance.
- Separate single-image intrinsic hypotheses from recovered physical material. Night illumination, wet reflections and emission are ambiguous; compare neutral relighting and integrated-context coupons before adopting inferred maps. Camera-space normals are not tangent-space material maps.
- Verify code, model, input-asset and output-use licenses independently before integrating research tools. A permissive wrapper does not remove upstream noncommercial terms, and a project page does not prove released inference weights.
- Preserve common correspondence when expanding aligned PBR exemplars. Reuse one synthesis transform across channels; rotate tangent normal components when rotating samples, rather than merely rotating their pixels.
- Review final-output-pixel crops before high-resolution delivery, then downsample the high-resolution master to the approved hero. Extra raster samples do not recover unseen structure; generate all deep-zoom levels from one coherent master, not independent diffusion tiles.
- Verify normalized render-border quantization before asserting an exact native crop size. Blender stores border fractions as float32; integer pixel-edge truncation can add an edge pixel at large masters. Compute the expected raster from the saved master/box fractions and retain the real crop, rather than resizing native evidence to satisfy a nominal 768-pixel assertion.

## Selective artwork emission

- Separate source-blue artwork detection from emitter selection. A Blue-minus-Red mask multiplied uniformly after exposure normalization can turn every printed wave and stray strip white-hot. With explicit material authorization, add a new sparse emission image in the existing mapped Artwork UV space; preserve the albedo graph, original textures, lights and shared bloom. Give LEDs a separate channel and energy from waves.
- Trace selected source-art strokes continuously at final texture resolution. Nearest-run selection per scanline can jump between neighbouring waves and create kinks or crossing filaments; inspect native border renders and replace unstable tracking with verified continuous control points. A broad ink-darkening rectangle can also black out blue source lettering: preserve the original ink branch unless an exact print-only mask is verified.
- Render a native baseline crop when the supplied current full frame is half resolution. Do not upscale it and label it native evidence. Judge full-frame-derived final crops separately from border previews because compositor bloom can differ.
- Force packed images to decode before auditing pixels after reopening. `image.has_data` can be false for every lazily loaded packed image; accessing `image.pixels` first and asserting a nonzero expected image count prevents an empty audit from passing.
- Raycast render-visible evaluated receiver geometry before diagnosing weak contact pools. Ignore `hide_render` and camera-invisible objects; separately authored caps/dew can cover the nominal ledge and be absent from its light-link collection. Link those actual receivers before increasing lamp energy, then separate the pool receiver from adjacent vertical walls to avoid detached hot spots.
- Do not assume globally smoothed ridge tracking preserves wave identity. A source-art ridge optimizer can still bridge neighbouring stripes at worn or horizontal sections. Verify source-coordinate grid overlays and native renders; replace crossing routes with explicit continuous control points rather than increasing the smoothing penalty.
- Keep blinded native comparison panels below the vision tool's size limit in both dimensions. A tall orb triptych can downsample and exhaust the three-load limit before all three panes are inspected; use a horizontal native triptych, retain incomplete verdicts, and obtain fresh fully inspected reviews without sharing prior scores.

## Texture-only rim repairs

- Inspect the reachable head-art branch before porting a rim fix. A theme may use a mapped shared luminance reference while another uses an identity-projected base image plus a float emission derivative. Repair only the contributing images; preserve UVs, Mapping, shader settings and every non-mask texel. Use evaluated full-scene visibility for feature measurements: a head-only BVH includes shell hidden behind other parts.
- Preserve generated float emission artwork with `image.pack()` and write the packed EXR bytes, or use a verified 32-bit EXR `save_render` path. Blender image `save()` can change the colorspace and re-encode values. Reopen the saved blend and assert both the original colorspace and byte-identical non-mask floats before rendering; a successful EXR save is insufficient.
- Treat a white-albedo repair and a visibly white result as separate gates. Measure each theme against its own reference; adapt the dark-recess threshold to night exposure and choose a verified recess seed rather than a coordinate that lands on a bright eye ring in another reference. If the repaired texels already saturate the shader's white stop but the rendered rim stays black, document the lighting/shader scope blocker instead of silently changing illumination or claiming all themes fixed.

## Final-pass composition

- Snapshot evolving status reports into event-specific artifact paths before hashing them for an append-only ledger. Keep the working REPORT editable, but do not make later status updates invalidate a pending event's evidence hash; preserve older rows and separately verify the final artifact set.
- Decode side-swapped labels before interpreting reviewer chronology. A judge can prefer the unchanged control while describing it as a new improvement; preserve its raw response and relative preference, but discard unsupported claims about which features were added. Keep reviewer preference, reviewer readiness and integrator acceptance as separate fields.
- Resolve native watch items with bounded evidence rather than another favorable judging round. Compare exact native crops, check actual clipping values and protected geometry, and retain known cross-region tradeoffs. A brighter lip can win both reviews while reducing front-surface point catches; use fixed diagnostics to locate the issue and native inspection to adjudicate it, not a pixel count as an aesthetic score.
- Distinguish a READY evidence package from an integration-approved asset. Carry explicit HOLD/integration_ready:false verdicts into experimental composition receipts and review pointers; do not convert a successful rebuild into visual approval or update production pointers. If the owner requested composition tests, label them unapproved experiments and preserve the accepted baseline.
- Recheck the component selection immediately before render admission: a deliver-first scene can be provisional and superseded while waiting for the shared lock. Freeze the exact donor hash and verdict, cancel only the owned unstarted queue if its source is superseded, and test the final donor under a new trial ID. Preserve cancelled provisional evidence instead of silently replacing its inputs. A later net preference with a new native craft regression is still HOLD under a no-regression integration gate.
- Resolve actual object-to-material bindings before judging surface coverage. A material named for a shell rim may shade the entire upper head while a head-pigment material covers only the underside; a successful shader edit on the wrong receiver is not a completed head repair.
- Never stack mutually exclusive stone top systems or duplicate dew layers for a hybrid. Keep one geometry/dew owner, import only the other lane's explicitly composable face material branch, preserve print inputs, and publish separate full variants with matched render settings.
- When a projected wet-coat pass suppresses existing front catches, ablate coat inputs separately from added normal detail on matched native borders. Restore only the demonstrated front branch through private material copies so shared top/lip materials retain their gains; then rerun full-frame counts and fresh swapped reviews. A repaired numerical regression does not transfer the predecessor's favorable verdict or override a new preference split.
- When a compact-glint repair passes a facet-only detector but native inspection still shows bands, ray-probe the exposed substrate between cells. Check generated droplet winding with evaluated normals before selecting reflective/transmissive geometry: an inward closed mesh can still produce attractive glints while being optically wrong.
- Diagnose top slivers on actual evaluated instances, excluding render-hidden legacy meshes. Preserve a candidate/candidate preference as such, but withhold a strict repair promotion when the named shape defect survives.
- Label full-frame overview scaling separately from exact native crops in judge packets, and verify crop-pane pixel equality against the source render. - Audit allowed shader socket edits across every actual Principled node name, including gap/secondary nodes. A hard-coded `Principled BSDF` allowlist can falsely reject a valid second-node coat edit; preserve the failed diff and require all node values and non-allowed links to remain equal.

## Pigment-under-coat qualification

- Verify actual prototype material identity before replacing a surface with an approved donor shader. Two regions may already share the exact datablock; call that prerequisite satisfied, preserve the shader, and isolate the remaining geometry/illumination hypothesis. Compression can change lit colour without any pigment edit, so measure rendered Lab separately from shader equality.
- Gate constant-planar coat normals on dark-body luminance before crediting a broad sheen. Removing bump/facet normal variation can brighten disconnected stone cells into a pale mosaic rather than form a continuous wet envelope. Preserve the base-channel audit, compare low-pass spatial profiles and native geometry, and reject a brightness regression even when coat separation technically works.

- Treat a luminance-based ink exclusion as a proxy, not semantic artwork preservation. Even with original textures/UVs unchanged and a zero colour delta on dark shader samples, mixed texture footprints can change rendered ink-edge pixels; retain the strict AOV maximum failure and qualify an explicitly padded semantic mask before claiming ink-pixel equality.
- Separate a deep-zoom pigment preference from a solved hero-scale finish. A smooth coat over stretched object-space noise can produce a real fine-value gain while leaving the dark head-back substrate untouched and oil-paint separation invisible. Preserve both reviewers' relative preference, but do not promote when the requested paired clean-win gate fails; stop the family rather than increasing amplitude automatically.

## Shared-host render memory

- Resolve a sampled semantic ROI to its actual visible receiver before deriving a shader gain. A lower “rear block” rectangle can hit a foreground slab while the named rear material shades the block behind an orb. Preserve the failed nomination, ray-probe multiple pixels, inspect an actual-receiver native panel, and remeasure that receiver; do not transfer the old ROI's luminance ratio. Ray hits alone are insufficient when a reachable shader has zero Weight or camera visibility differs.
- Preserve lower-threshold compact-highlight tests when lifting albedo. A diffuse gain can leave the .24/.32 bright cores compact while joining .18 body regions into long pale facets; retain the complete frozen threshold sweep rather than reporting only the strongest-core PASS.

- Preflight Blender compositor socket APIs before admitting expensive renders. In Blender 5.2.2, Box Mask uses `inputs['Position']` and `inputs['Size']`, and Blur uses `inputs['Type']='Gaussian'`; legacy `box.x` and `blur.filter_type` raise AttributeError. An apply-twice graph/fixture PASS is only technical readiness: if resource admission blocks all captures, publish RESOURCE_HOLD with no selected recipe or integration pointer, rather than presenting unrendered variants as tested looks.

- Deduplicate appended image datablocks only when encoded bytes, colorspace, source type and alpha mode match an existing image. Preserve every sampler property and compare the complete donor shader using content identities, not volatile image names. Record the substitutions; this avoids allocating duplicate 4K PBR maps without changing the material recipe.
- Diagnose long render silence with process state, RSS/swap and GPU allocation before calling it a deadlock. A process in `folio_wait_bit_common` can still complete under host swap pressure. Run candidates in separate sanitized Blender processes under the shared GPU lock, use tracked background execution to survive foreground tool transport limits, and wait for real receipts. Do not lower requested resolution/samples or stop unrelated jobs to conceal resource pressure.
- Check the historical render receipt as well as saved Cycles settings: a scene can retain 64 samples while its accepted capture was rendered with a runtime 96-sample override. Match the requested capture settings explicitly and document the saved-file discrepancy.
- Treat CPU fallback as a separate host-memory admission decision, not a free substitute for unavailable VRAM. Inspect concurrent Blender jobs, per-process RSS/swap, page-fault progress and saved CPU thread count; unrelated CPU lanes may bypass the GPU lock. Under prolonged thrashing, preserve verified builds and transfer the live queue to the coordinating parent with exact process handles rather than claiming completion or spawning duplicate renders. Do not change other jobs or global memory policy.

## Per-instance surface hugging

- Set Scale Instances' global-space Center to the instance Position when compressing growth along a world/support normal. With Local Space disabled, the default zero pivot can scale instance locations toward the world origin and bury foliage; unchanged source points and object-count guards do not catch that. Verify evaluated instance origins and real native coverage before interpreting a thinner render as aesthetic success. Preserve root clearance from the visible faceted layer, not merely its recessed substrate.
- Preserve newly orphaned original Geometry Nodes groups with fake users before a copy-on-write build/reopen audit. A correctly copied scatter group can make its source zero-user and disappear on save; retain the failed receipt and distinguish that ownership issue from shader/geometry drift. Update the view layer before hashing newly positioned lights so a stale matrix is not mistaken for a reopen mutation.

## Point-cloud bead and runner polish

- Inspect each inherited bead point cloud's actual attributes and Geometry Nodes scale source before thinning it. Some families use a per-point `scale`, while others use a constant node scale and have no such attribute. For the latter, remove only verified edge-free/face-free owned points on a copied scene, preserve the node graph, and retain the failed attribute-assumption receipt. Reopen and compare all non-owned geometry/materials before rendering.
- Measure visible bead rhythm separately from authored spacing. Occlusion and multiple overlapping strand families can keep nearest-neighbour variation nearly unchanged even when authored intervals become clustered; report top density, spacing quantiles and detector overlays rather than claiming authored randomness proves target-like rhythm.
- Repair a support-ray jump before merely rounding its corners. Chaikin/Bezier smoothing can turn a wire kink into a rounded hook and detach beads left on the old centreline. Preserve the failed native crops, filter the actual support route, and transfer each bead's residual offset from the old centreline to the new curve; this retains deliberate burial while reattaching visible cores. Verify both the hook and core contact at true final-density pixels.
