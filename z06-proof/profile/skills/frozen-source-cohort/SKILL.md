# Frozen source-backed cohorts

## When to Use

Use for multi-harness studies that need identical executable prompts, private source bindings, fail-closed preflight and independent evidence oracles without modifying production memory implementations.

- Separate repo-safe exact prompts/slot/oracle contracts from concrete private bindings. Preserve source IDs and native lookup identities exactly; content hashes are revisions, not substitutes for origin/session provenance.
- Keep prompt language answer-independent and hash the final UTF-8 prompt. Withheld-source variants must omit a previously validated binding and reject expected-value leakage through prompt text or metadata; infrastructure failure is not a missing-evidence test.
- Validate every required slot before any study model invocation. Independently ground native coordinates, source bytes, authentic times, expected fact support and original-file revision/baseline linkage. Incomplete cohorts fail as a whole, not as qualifying partial runs.
- Pair ordered updates for the same mutable fact separately from genuinely incompatible assertions for one fact/scope/validity. Literal spans establish byte support, not semantic relationships; require independent curator review. Preserve relevant original quote context rather than inventing labels or weakening the oracle.
- Establish minimum-subset necessity from information removed, not slot labels: reject duplicate native records/excerpts and cross-supporting values. Measure a defined deduplicated full-source byte baseline without claiming single-observation superiority.
- Keep expected-value oracles private and pinned; compare actual supplied evidence against their approved projection before answer scoring. Negative-control corrupted evidence must fail the checker.
- Capture actual retrieval, model-visible assembly and serialized request, authoritative answer, and independent verification separately. Response serialization is not injection. Label offline UNIT responses and no-model seam checks as diagnostics, never cohort outcomes.
- Test the real cohort constructor directly against each consumer interface, including mutations; independently implemented synthetic plan builders can conceal interoperability mismatches.
- Pass the original external extractor's actual output through the original consumer before authorizing expensive downstream work. A successful export or skill-sampler pass does not prove that a training formatter accepts the same representation; retain a native-format positive control and source/session lineage. Before proposing a new converter, exercise the provider's existing preparation function: a direct-format failure can coexist with a working original preparation path. Check separately for tool-event and grouped-provenance loss.
- Inspect every reachable fallback before treating an advertised dry-run as read-only or inference-free. Exercise the original entry point against an owned loopback fixture with POST refused, alongside a healthy GET-only control; never probe production endpoints to establish this safety property.
- Classify retained analytical scripts by reachable behavior, not their names or read-only docstrings. Reports may write canonical exports and summaries, while a grading revision may launch graders when an input is missing. Inspect before execution, stage only required original inputs in an owned private output root, run unchanged no-model analyzers there, and keep missing-input/failed staging receipts separate from source drift or efficacy.
- Bind producer code, committed reports and retained raw artifacts separately. Verify each claimed Git-pinned artifact against the exact commit's blob; a file beside a checkout at that SHA may be untracked and generated by a dirty producer. A matching local digest proves frozen bytes, not producer-revision attestation. Preserve reproduced aggregates with this provenance limitation rather than claiming immutable source lineage or rerunning a protected capture to manufacture it. Capture Git blob stdout as binary for byte hashes: a terminal's rendered text may trim the final newline and create a false source-drift finding.
- Attest the executed CI checkout separately from run/job branch metadata. Pull-request workflows may execute a merge revision while head_sha remains the branch tip; read the actual checkout log and verify the merge-parent relationship before attaching test evidence to a tree. Treat late-arriving reviews as changing source: preserve the original snapshot, refresh the exact-head mapping in an owned verifier, and never transfer an earlier review or unchanged-file proof into aggregate latest-head acceptance.
- Gate preparation-only bridges before importing pinned provider bytes: reject dirty or symlink-substituted sources, mutable phase/command/verifier manifests, incomplete or overlapping native grouping, and tool semantics the unchanged formatter cannot preserve. Check native events as well as extracted rows, because an extractor can drop orphan results. Treat source hashes as byte checks, never origin identities; keep producer-asserted work/protected mappings explicitly unqualified. Reuse existing grouped splits, prepare train rows only, and prove the actual CLI under a denied-network namespace plus import/function tripwires without invoking training or health fallbacks.
- Bind extracted message order, content and metadata to the unchanged extractor's projection of captured native bytes; matching source/corpus hashes alone cannot prove that the row was actually extracted from that source. Re-extract only the owned single-file snapshot, not ambient personal history.
- Audit each independent assertion against its stated contract and exact revision. A refusal with the correct exit and no artifacts can still fail an incidental diagnostic-word assertion; a line-number fault injector can falsely pass after code moves. Preserve the original test and result, document fixture corrections, require proof the fault actually fired, and never weaken material state/output assertions.
- Exclude cross-partition copies of actual prepared message content and shared native branch-event identities separately from full-file hashes and producer work labels. Changed timestamps can defeat source-byte equality without making copied conversations independent.
- Persist thin private bindings, selected evidence and verification outside Git with restrictive permissions. Keep original transcripts authoritative and out of the evaluation repository. Preserve a truthful blocked artifact with zero fabricated receipts when real sources cannot qualify.
