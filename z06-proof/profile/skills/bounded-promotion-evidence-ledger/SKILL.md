# Bounded promotion evidence delivery

- Read current top-level routing before historical project queues. Preserve old queues as provenance; do not infer an old canonical heading still controls publication.
- Save paginated issue comments and PR metadata locally. Assert collected counts equal declared counts; deduplicate URL inventories programmatically. Source-table rows and open-PR inventories are not independently qualified contributions.
- Reconcile merged owner PRs before testing a competing fork. Preserve original author/report/review credit and mark stale candidates owner-covered.
- Store executed command, cwd, exit, duration and raw log. Retain setup failures and timed-out reruns; environment repair does not erase them. Focused passes do not imply aggregate acceptance.
- Use committed JS package-manager pins and official runners. Filtered installs can omit a local lint-plugin workspace: include the actual workspace dependency, rather than switch runners or suppress loading.
- Prepare documented vendored/preload dependencies with their official locked install/build before network-isolated tests. Retain the offline-preload failure and rerun the same official suite; never stub the prerequisite.
- Verify clean Git worktrees after controls. For source archives, hash all original regular members against the tested extraction to prove source preservation.
- Treat old claimed/working labels as unresolved, not live-process evidence. Executor stays unknown until coordinator correlation; lease expiration is not a posted release.
- Deliver a local-only manifest/bundle and short draft payloads on existing project carriers. Exclude host paths/raw logs from public drafts, retain denied-write holds, and require parent review/dedupe/readback.
