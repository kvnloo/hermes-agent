# Tern SDK draft qualification

## When to Use

Use for isolated review, gate repair, and cross-PR composition of native Tern TypeScript frontend drafts.

## Native report sheet gates

- Target `Surface.scroll` at the Markdown descendant inside the native body, not the overlay shell. Prove long-body scrolling by painting the final paragraph after End; native tree captures may omit far-offscreen paragraphs, so absence before scrolling does not prove Markdown truncation.
- Preserve main-region identity and composer draft/caret, and keep pending approval prompts above asynchronous inspection reports. Exercise native dock View and Close callbacks through the SDK surface, not only helper functions.
- Resolve native action names from the owned snapshot: accessibility collapses title whitespace. If a clickable AX group lacks a unique tree-host identity, select its unique visible text descendant through the same guarded adapter rather than weakening ownership checks. Use canonical `ArrowDown`/`ArrowUp` names with the E2E engine's key parser.
- Prove native editor visibility geometrically after long-body scrolling: semantic edit delivery and focus alone can pass while an input is clipped beneath a sticky decision bar. Require the complete input rectangle above the footer and inspect the captured screenshot.
- Distinguish `/plan` prompt-generation builtins from structured review contracts. A generated prompt is ordinary user intent, not an approval authority; review decisions must use the normal submit/queue path and preserve an unrelated composer draft.
- For strict E2E TypeScript checks, link only the authorized worktree's ignored `ui-tsp/e2e/node_modules` to the installed E2E framework's node_modules when `e2e/engine` is unresolved. Do not weaken strictness or modify shared dependency trees.

## Semantic LSP receipts

- Back semantic views with actual Hermes LSP request producers and generated contracts; preserve unavailable/error versus successful null/empty results. Read-only UI inspection must not fabricate model tools or transcript rows. Test framed subprocess traffic and normal stored-message replay separately.
- Wait for authoritative session locality before asserting native file links. A locally spawned E2E gateway can initially lack `session.info.terminal_backend`; early inert links are not evidence of an attached/remote transport. Preserve the fail-closed guard and assert the confirmed re-render rather than weakening locality.
- Capture narrow symbol views before later fixtures scroll them offscreen. Native tree labels may ellipsize; retain full wrapping linked location rows and inspect actual pixels as well as wire payloads.
- Use a trusted config-declared mock server with its exact command for semantic service tests. A built-in binary override may replace only argv[0] and still append the built-in server flags, which can invoke Python with invalid language-server switches.

## Config-backed binding projections

- Keep binding configuration in Hermes `config.yaml` defaults/schema and project it through session-scoped `settings.get`; never add a behavior environment variable or infer profile identity from cwd. Bind both reads and Settings readbacks to the live session, and retire older same-session reads after a newer accepted readback.
- Validate effective bindings atomically, including normalized modifier aliases, duplicate scopes, permissive legacy-modifier overlaps, early-interrupt collisions, host-owned Meta aliases and printable/composer editing keys. Preserve modal-local ownership for rebound clear actions; the explicit owned interrupt is the deliberate exception.
- Keep invalid on-disk bindings editable in Settings even when the keyboard projection is rejected. Load fields before reporting projection errors, retain last-good/default bindings, and exercise repair/reset via native prefs callbacks. Canonical sparse config writers may omit default empty maps and null leaves: assert effective RPC readback plus absence of stale overrides, not literal `{}` bytes on disk.

## Procedure

For ordered eval companions, preserve literal stdout and explicit call/cell/work/view IDs rather than splitting arbitrary text. Define span offsets in Unicode code points (Python and JS UTF-16 indices differ); replace only the exact retained printed span and keep unmatched/clipped text literal. Keep nested-work state outside output folding, scope callbacks per execution in sequential and concurrent dispatch, retire them on completion, and copy snapshots before emitting so late RPC work cannot mutate sent history. Regenerate typed events and use the recognized `_emit` seam so contract completeness inventories see the actual emission.

1. Read each task issue and PR discussion, then isolate each head in an explicitly authorized worktree. Preserve original commits and add separate integrator commits. Recheck the remote SHA immediately before a fast-forward push; never force-push a concurrent author's branch.
2. In a narrow-fetch clone, inspect `remote.origin.fetch`. Fetch task branches with explicit `branch:refs/remotes/origin/branch` refspecs and per-command `-c fetch.prune=false`; ordinary fetch can leave the remote-tracking reference absent, and configured pruning can remove other explicitly fetched refs. Do not broaden shared clone configuration just to make a task work.
3. Run the owning frontend's typecheck, complete Vitest suite, and eslint. Report warnings separately from errors. Python gates apply when Python changed; generated contracts require canonical regeneration, not hand edits. If an interpreter loads another Python minor version's site-packages, diagnose `sys.version` and `sys.path` before installing anything; use an already provisioned matching test environment through `HERMES_PYTHON` and clear inherited `PYTHONPATH` for direct generator invocations.
   For event-fed jobs views, verify process lifecycle events cover silent, non-notifying exits: output streaming alone cannot keep running counts authoritative. Keep a deferred event-coalescing timer owned by the open sheet, clear it on close/replacement/quit, and prove an outstanding list cannot start a tail after close. Restore real timers before awaiting SDK shutdown in fake-time tests so the harness itself cannot deadlock.
4. Inspect SDK `View` regions by semantic id (`main`, `dock`, `layer`), not guessed array positions. `View` children are `Tree` wrappers, not JSX `Node` instances; an `instanceof Node` filter can silently hide the emitted node under test.
5. For input acceptance, complete the SDK Session handshake before emitting key bytes. A rendered fixture without a handshake does not prove keyboard routing. Dispatch rendered actions through `surface.dispatch` and assert actual state/output, not only helper callbacks.
   Bind busy-input preference reads to session adoption, Settings close, or an explicit command rather than every turn start: an unmocked gateway request allocates transport deadlines and can break idle/orb timer invariants. Exercise adoption in the new input fixture instead of manually seeding its cached setting. Keep approval-owned drafts on the existing acknowledged `request.answer` deny transaction before `prompt.submit`; a raw `respond()` spy does not prove this path.
6. For live-window UX fixes, render the actual App/builders in isolated `tern serve` and assert painted native text plus geometry at measured 80/100/wide PTY columns; wire/state assertions alone miss duplicated tool headers, empty thought disclosures and flex squeezing. Use whole native `status`/`seg` priorities (larger survives), a zero flex basis/minimum, and the existing `omp.composer.extras` role to avoid generic status caption/location injection. Capture compact picker scope menus as well as wide sidebars: compact menus omit group headings by design. Keep audio opt-in affordances out of the idle dock while preserving the explicit consent shortcut. Prove the same assertions red with verbatim base renderer sources, preserve before/after PNG/layout/tree dumps, and distinguish a signed-out ordinary-window gate from headless results.
   For run boxes, keep the footer outside output-only folding. Native whole-tool previews count command/error/footer rows, so a footer claiming N output lines can lie or disappear. Terminal and execute_code finalize ANSI-stripped output; render that as wrapped text/code rather than an unbounded virtual ANSI terminal, and verify real native output height, exact blank-inclusive line counts, and expand/refold actions. Match the terminal timeout suffix retained by finalization rather than assuming its internal timeout flag reaches JSON. Test newest-card behavior with multiple cards and real approval overlays. For copy actions, verify exact OSC 52 bytes and the real notice path on a write exception; do not claim OS clipboard acknowledgement.
   For incremental ANSI, keep the entire retained terminal text on the SDK node and use native `preview.lines`, rather than slicing raw ANSI lines and losing parser state. Give an ANSI output column inside an icon/result row `grow: 1` and an explicit preview height even for short streams. Verify pixels as well as wire: native-rasterized ANSI is absent from DOM text/AX captures, and a frame acknowledgement can precede its paint. Filter the backend's private CWD trailer across arbitrary read boundaries before publishing raw deltas; finalization strips it only after capture. Warm resume must reconcile any durable unfinished-call stub with the live snapshot so it does not create two cards.
7. Exercise todo updates without creating a newer tool call. Otherwise a test can miss mutation of completed historical snapshots. Separate the latest gateway plan from tool-completion snapshots, and prove both the new projection and old immutable card.
8. If the requirement specifies completed-only counts and a precise summary, do not substitute a native HUD whose counts include dropped tasks. Test exact summary text and SDK-dispatched disclosure. Keep progress gateway-derived and idle work event-driven.
9. Probe cross-PR composition in a detached scratch worktree, in requested order. Record automatic conflicts before resolving them. Shared function signatures and view cache keys must preserve both features; new required context fields also need combined fixtures. A green manually resolved composition is not a clean-merge receipt.
10. For SDK media compatibility, inspect the pinned `typescript/src/wire.ts` and `typescript/src/props.ts` (not obsolete root `src/` paths). Negotiate the `media` node via `caps.kinds`, not a made-up feature flag. Keep the local adapter to the SDK's `path`, optional `rev`, and optional `link`; path-backed nodes need no blob transfer. Native viewers must not inherit code-line clipping: inspect a real screenshot after wire tests pass. Update partial Session capability fixtures when consuming a newly used required capability field.
   For completed write figures, require the backend's actual `WriteResult.verified` and byte count, keep SVG/Mermaid in native fences, and use extension-specific MIME checks. Bind figure keys to owning call/source/result identity; never put a content fingerprint in the media node's git-only `rev`. A local-looking absolute path is not host-local proof: require a non-attached gateway plus the session's explicit local terminal backend before exposing model viewers/file links. Include that locality in both transcript and retained-history cache identities so a backend change removes a stale local viewer. Keep remote source/path fallback explicit and label path-backed models as current-file views, not immutable historical snapshots.
   For terminal clock preferences, include negotiated `caps.hour12` in both the entry-node cache and Retention's context identity; invalidating only the user node cannot refresh already-retained history. Test a locale opposite to the terminal preference, a second hello and a missing-preference 24-hour fallback. For file syntax, verify installed `CodeProps.path`/`DiffProps.path` and generate the installed host declarations to an owned scratch directory with `tern plugin types DIR`. Send original file paths without a competing `lang` (which wins over path), preserve snippet languages and existing `fileHref` routing, and keep unknown/older-host code readable as literal text. The official node reference is `elements/text.md`, not nonexistent `elements/code.html` or `elements/diff.html`.
   For composer attachments, verify the installed input protocol before assuming paste/drop events: SDK 0.1.0 delivers bracketed paste as a `paste` key and selection pastes as `edit`; a forward-compatible unknown-event adapter is not documented native API evidence. Bind submit to gateway-confirmed paths and retain an explicit empty selection through queue-envelope creation and drain so a later draft's staged images cannot leak into a text-only turn. Exercise real file bytes, deferred confirmation, removal-before-confirmation, and failed-detach retry.
11. For targeted destructive transcript actions, preserve the gateway's durable `row_id` on resume and `prompt.submit.user_row_id` on live entries; presentation entry IDs are not rewind targets. Preview the authoritative turn count without mutation, bind confirmation to a history token and exact durable row identity, and test cancelled/stale callbacks plus failure preservation of draft/history. Validate new value constraints in the handler before mutation: the dispatcher can reject unknown keys while only checking accepted value types after the handler returns, so a Pydantic declaration alone is not an admission guard.
12. For tool-adapter registries, preserve existing run-box presentation callbacks, native-media capability plumbing, and edit diagnostics by keeping their builders untouched. Use own-property dispatch so names such as `constructor` and `__proto__` reach the generic fallback. Confirm result fields in the Python implementations, including native multimodal `meta.screenshot_path` and `text_summary`; never invent a blob identifier from embedded image bytes. When Markdown reads change node kind, keep source-code wrapping assertions meaningful by changing only their non-source `.md` fixture path to a source extension, and disclose that fixture migration.
   For native-browser providers, use the documented daemon CLI only with pane/window identity and verify that identity in the real isolated lane. `tern serve` can expose `TERN_WINDOW_PANE`/`TERN_WINDOW_SOCKET` without a session daemon or `TERN_PANE`/`TERN_WINDOW_KEY`; that proves fallback, not native browser support. Do not synthesize aliases to force adoption. Preserve Alt+B word editing when selecting browser shortcuts. Imports used in rebound gateway methods must live inside the handler/helper: `bind_module` binds functions to server globals, not the sibling's imported exception classes.
13. For complete-result cards, remove renderer-side array/character clips rather than merely toggling native collapse; dispatch the rendered disclosure through the real Surface and assert the last retained item. Keep source returned/total/omitted counts (including lower-bound totals) independent of folding. Ground artifact links in `full_output_path`, execute_code's `stdout_spill_path`, or web_extract's exact stored-result footer; never infer a cache artifact. Sanitize display labels only after deriving links from raw paths, and keep unsafe control-byte destinations inert instead of retargeting sanitized filenames. Consume actual dense `matches_text` search results as well as verbose matches. Split concatenated difflib patch sections with hunk counts so header-like removed/added source lines cannot manufacture file identities.
14. Post one receipt per PR with exact head, commands/counts, repaired causes, and unverified native/real-window boundaries. Read back each exact comment and pushed head; leave drafts and authorized worktrees intact unless asked otherwise.
15. For the native E2E lane, use the test-owned `scripts/dev/tern-e2e.sh TARGET --node NODE` runner; preserve signed-out native blocks and label independent `tern serve` evidence separately. Alt/F1 shortcut control can use a narrow allowlist with the adapter's owned-snapshot preflight/postflight; do not enable Ctrl chords on the known Linux Ctrl-to-Meta host. A read-only `/context` check needs an exact gateway allowance plus refusal tests, not blanket `slash.exec` permission. Run frontend gates, strict E2E tsc and canonical Python harness tests before publication; if bootstrap lookup fails, the runner's documented explicit `HERMES_PYTHON` path is preferable to bypassing the canonical test runner. After a normal lane push, GitHub may briefly report OPEN before ancestry processing marks included PRs MERGED; reread `state,mergedAt,mergeCommit` before claiming success.
