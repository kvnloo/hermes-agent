# Sport rules with detached Bend evidence

## When to Use

Use when extending a sport-blind rules kernel with governing-body profiles, property tests, detached Bend laws and native CPU/CUDA parity evidence.

## Gates

- Keep physical observations sport-blind. Accept referee/adjudicator decisions through typed, deterministic, explicit-state reducers and the existing opaque lifecycle adapter; never infer a goal/foul from an assumed physical pack.
- Freeze the governing-body edition and cite numbered provisions. If a publisher blocks PDF/HTML access, distinguish retained publisher text, a federation's frozen official mirror, and search-index excerpts. Never silently substitute `/latest/` for a pinned edition.
- State the projection boundary beside the laws. Separate full TS lifecycle/roster/clock administration from the smaller Bend executable projection; finite parity is not a refinement proof.
- Write independent expected scoring specifications in LAWS rather than comparing actual scoring against its own implementation helper. Mutate isolated model copies and require the corresponding exact-delta law to reject each sport's sabotage.
- Prove actual-step rotation cases, not just that a standalone rotate helper cycles. Reachability claims must fold real transitions from initial state and carry an invariant hypothesis for forged terminal values.
- Use whole-second Nat clocks in Bend and explicit millisecond conversion in TS adapters. Large unary literals such as 600000 can overflow the checker's machine stack even though a typed file without normalization checks.
- Recheck with the existing Lean 4.34 toolchain, host clang first on PATH, and save direct CLI/source/book/tool identities. An isolated Hermes adapter cold-kernel timeout or missing Lean is a failed adapter, never a portable PASS; direct `--verdict` is separate evidence.
- Build with CUDA_HOME=/opt/cuda and require a sibling .gpu file. Serialize execution with /tmp/claude-1000/render.lock, check >=2GiB free, and use --gpu off, --gpu on --gpu 1GB, and --gpu 1GB. The last cap prevents reserving the entire shared card. Do not bypass a long render queue.
- Start lock-waiting qualification as a tracked background process; a foreground tool timeout can kill a long queued wait before the GPU job begins. Complete or explicitly hand off the owned process before ending a subagent.
- Freeze source bytes before compiling/qualifying. If even whitespace changes the model, rebuild and refresh hash-bound proof/GPU receipts before claiming that evidence binds final sources.
- Compare actual TS reducer tapes with native output, and compare CPU/CUDA stdout plus nvidia-smi samples. Label U32 aggregate checksums as finite/collision-prone evidence, not per-tape equality or GPU speedup.
- Run functional suites with bounded workers on a busy shared host; keep the existing wall-clock statistical test unchanged and run it separately. Report baseline failures, retries and final counts, not just the green subset. An ESLint exit zero with ignored TS files is not TS lint coverage.
